# 3–6 岁幼儿气质与兴趣测评体系

一套面向 **3–6 岁幼儿**家长的「发展优势 + 兴趣画像」测评工具：家长在线填写**自适应问卷** → 导出结构化结果 → 由分析 **skill** 生成个性化的发展分析与「游戏 / 锻炼 / 家庭陪伴」建议报告。

> ⚠️ **定位与边界**：本工具是**发展指导性质的画像**，**不是医学/心理诊断工具**，不下临床结论。结果为「个体内相对优势」的描述，并非人群常模百分位。若对孩子发展有担忧，请咨询儿童保健科或专业人士。

## 目录结构
```

processed/      已处理归档（运行时数据，不入库）

```

## 🔒 隐私与数据处理
- 问卷为**纯静态 HTML、无后端**，儿童数据**不经过、不存留任何服务器**（已确认无 `fetch`/`XHR`/`WebSocket`/外部 `src`/CDN）；家长在本地导出文件后自行发送。
- 身份信息**最小必要 + 昵称化**：出生年月、性别、昵称、`child_id`（**单次会话随机标识**，仅标记本份作答、跨次不可自动关联、非稳定身份），以及填写人与孩子的关系、每日相处时长（后两项用于在报告中说明观察视角并供 skill 判定数据熟悉度，导出在 JSON 的 `_identity_extra`）；含知情同意声明。
- **本地草稿留存**：为支持中途暂存/续填，作答草稿（含昵称、出生年月、`child_id`、全部作答）以**明文保存在用户本机浏览器的 `localStorage`**，提交后仍保留；此数据**仅在用户本机、不上传任何服务器**，用户可在完成页「清除草稿」一键移除。
- **保留与删除权**：数据全程只在用户本机、由用户掌控——可自行决定保留多久，亦可随时一键「清除本机草稿」彻底删除；导出文件是否分享给他人由用户自主决定。由于本工具从不接收/存储数据，无需也无法「向我们申请删除」。
- **面向家长的隐私说明**：见 [`docs/隐私说明.md`](docs/隐私说明.md)（采集字段与用途、纯本机不上传、草稿明文留存与一键清除、保留/删除权、非诊断声明、PIPL 与儿童个人信息保护合规要点）。
- `inbox/ processed/ reports/` 内的儿童问卷数据与报告**已被 `.gitignore` 排除（`inbox/* !inbox/.gitkeep` 等模式，三目录均保留 `.gitkeep` 占位），绝不提交到仓库**。
- 若仓库为公开（public）：代码与文档公开无妨，但请务必确保**任何真实儿童数据都不要提交**。

> 导出数据契约：人读说明见 [`docs/json-schema.md`](docs/json-schema.md)，机读事实源见 [`schema/export.schema.json`](schema/export.schema.json)（JSON Schema draft 2020-12，`schema_version` 1.1）。

## 设计决策摘要（16 项）

| # | 维度 | 定论 |
|---|---|---|
| 1 | 定位 | 发展优势 + 兴趣画像（**非诊断**·个体内比较） |
| 2 | 覆盖 | 气质 / 社会情绪与自我调节 / 发展快照 / 兴趣 / 学习品质 / 家庭背景 |
| 3 | 年龄 | 一份**自适应**问卷，按出生年月分 3–4 / 4–5 / 5–6 切题，结果带 `age_band` |
| 4 | 题目来源 | 框架对齐 CBQ/DECA/ASQ/学习品质 + 中文自编 + 每题挂构念出处 |
| 5 | 评分方式 | 纯家长报告；行为题 5 点频率、兴趣题 5 点喜爱；参照「最近 2–4 周」 |
| 6 | 长度 | 标准版 ~70–85 题 / 12–18 分钟；分页 + 进度条 + 暂存 + 开放题 |
| 7 | 计分解读 | 个体内 ipsative 相对优势 + 描述性锚点 + 匹配度 + 软提示（**逻辑全在 skill**） |
| 8 | 托管回流 | 纯静态 HTML + 客户端导出 + 朋友发 JSON；无后端、数据不落服务器 |
| 9 | 导出 | PDF（作答回顾）/ XLSX / **自包含 JSON（skill 权威输入）** / MD |
| 10 | 计时 | 分块 + 总时长 + 起止时间戳 + 续填标记（活跃时长），作软置信参考 |
| 11 | 身份隐私 | 最小必要 + 昵称化 + 单次会话随机 ID（跨次不关联）+ 知情同意 |
| 12 | 报告形态 | 详尽报告 + 一页速览 |
| 13 | 建议引擎 | 循证**活动库** + LLM 按画像裁剪组合（建议可溯源） |
| 14 | 报告交付 | Markdown 源 + 响应式 HTML（手机最佳）+ A4 PDF；含雷达/条形图 |
| 15 | skill I/O | `inbox/` 约定，批量/单份都支持，输出 `reports/`，归档 `processed/` |
| 16 | 节奏 | 分阶段 + 评审门 |

**诚实边界**：无样本 → 不做信效度实证（「严谨」靠构念效度 + 来源透明 + 局限声明）；全程非诊断；只引可核实文献、不编造。
