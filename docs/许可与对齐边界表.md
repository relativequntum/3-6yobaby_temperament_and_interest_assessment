> 版本：2026-06-03 ｜ 负责人：版权/许可合规复核（只读 item-bank，**不改题库**）
> 目的：对每个被对齐的「母量表/框架」逐行说明 —— 它的版权/许可状态、本工具**采用了什么**（仅构念名/高阶因子/锚点写法风格）、**明确未采用什么**（**原始题目文字 + 整套子维度的选择与排列顺序**）、以及对应 `item-bank.json` 的 `source` 缩写键。
> 合规铁律（与 `理论依据与方法学.md §6.2` 一致）：**版权保护的是题目的具体表达与量表的整体编排与子维度选择/排序，不保护构念名称与理论。** 本工具引用构念、标注出处（学术规范），但**所有题目用中文重新撰写、不照抄、不做成任何受版权量表的可填写电子版**。
> 风险标记：🔴 = 需用户决定的同构风险（见末尾 FLAG）；🟢 = 低风险；🟡 = 中等/需发布前自查。

## 2. T-3 同构判定：本工具 SEL/TMP 子维度的「选择 + 排列顺序」是否与 DECA-P2 三保护因子 / CBQ 维度集「高度同构」

> 法律前提：**版权不保护构念名，但保护「子维度的选择与编排（selection and arrangement）」**——即便每道题都是自编，如果**挑哪些维度、按什么顺序组织**与母量表的**独创性编排实质性相似**，仍可能落入汇编作品(compilation)的保护范围。下面对两组分别给出明确判定与依据。

### FLAG-A — TMP vs CBQ 维度集

- **本工具 TMP 实际编排**（取自 item-bank，7 个报告侧子维度）：活动水平 → 社交接近 → 害羞/慢热 → 趋避/适应 → 冒险/高强度愉悦 → 挫折/愤怒反应 → 可安抚性 → 恐惧/谨慎 → 注意聚焦/坚持 → 抑制控制（按 §3.1 归并为 7 维，挂三高阶因子 Surgency/Negative Affectivity/Effortful Control）。
- **CBQ 维度集**：15 个一阶维度 → 3 高阶因子。
- **判定：低度同构 / 不构成侵权性同构（🟢，但保留 🔴 标记待用户确认）。**
- **依据**：
  1. 本工具**只选取了 CBQ 15 维中的一个子集并重组为 7 维**，**未复刻 15 维全集**，也**未沿用 CBQ 量表手册的题目排列顺序**（CBQ 题目是随机交错呈现的，本工具按子维度聚类自编）。维度**选择是不同的子集、排列是重新组织的**，与 CBQ 的独创性编排不构成实质性相似。
  2. **三高阶因子（Surgency/NA/EC）属于科学事实性的理论结构**（Rothbart 心理生物学模型），在多文化样本可复现，属**不受版权保护的思想/事实**，采用它不侵权。
  3. 题目文字 100% 自编、场景本土化。
- **结论**：TMP 与 CBQ **不构成「高度同构」的版权风险**；维持现状即可，**无需重构**。仅需在发布前确认 CBQ「研究用途」授权边界（本工具为家长自我了解工具、非 CBQ 量表分发，应不触发 CBQ 授权义务，但**建议用户向版权方书面确认**）。

### FLAG-B — SEL vs DECA-P2 三保护因子

- **本工具 SEL 实际编排**（取自 item-bank，5 个报告侧子维度，挂构念）：情绪调节 + 行为与冲动控制（→ 自我调节面）→ 主动性与自主（→ Initiative）→ 依恋与关系（→ Attachment）→ **共情与亲社会**（→ Empathy & Prosocial）。
- **DECA-P2 三保护因子**：Self-Regulation、Initiative、Attachment/Relationships（恰好三个、且为 DECA-P2 的招牌结构）。
- **判定：🔴 中-高度同构风险，需用户决定。**
- **依据（为何标红）**：
  1. 本工具 SEL 的**前三块（自我调节 / 主动性 / 依恋关系）与 DECA-P2 的三保护因子在「维度选择」上几乎一一对应**，且名称语义高度接近。DECA-P2 的「**恰好这三个保护因子的组合**」本身是其有独创性的编排选择，三者并列的「选择」与本工具实质相似度较高。
  2. 缓解因素（已部分拉开距离，故不是「完全同构」）：本工具**额外新增了第 4 块「共情与亲社会」**（来自 Hoffman/Dunfield/Eisenberg，非 DECA），把「自我调节」**进一步拆为情绪调节 + 行为冲动控制两块**（DECA 是合一的 Self-Regulation），排列顺序也按自编逻辑重排；题目文字 100% 自编。
  3. 残余风险：尽管有新增维度，**「自我调节 + 主动性 + 依恋」三件套并列**这一核心选择仍可被认为「取自 DECA-P2 的独创性维度组合」。在「优势/保护因子取向 + 学龄前 + 家长报告」这一狭窄赛道里，DECA-P2 是最知名的三保护因子量表，**同构的可识别性较高**。

### 🔴 风险提示与「如何拉开距离」的建议（不擅自重构题库，交用户决定）

> 以下为**建议**，本轮**不修改 item-bank**。是否采纳由用户拍板。

- **建议 B-1（最小改动·重命名+重排）**：把 SEL 子维度的**对外命名与排列顺序**改为不与 DECA「Self-Regulation / Initiative / Attachment」一一对应的形态，例如以「情绪调节 → 共情与亲社会 → 主动性与自主 → 依恋与关系 → 行为与冲动控制」重排，并在文档中以中文功能名为主、淡化与 DECA 三因子的逐一映射。降低「三件套并列选择」的可识别性。
- **建议 B-2（出处分散）**：SEL 各子维度的 `source` 已部分挂在 Thompson/Kochanska/Diamond/Hoffman/Dunfield/Eisenberg/ZahnWaxler 等**非 DECA 文献**上，仅 `DECA-SR/IN/AT` 显式指向 DECA。可考虑把 DECA 出处降为「理念参考」之一、与上述文献并列，避免给人「以 DECA 三因子为骨架」的印象（与 SEL-11 已去除 SDQ 出处的处理同理）。
