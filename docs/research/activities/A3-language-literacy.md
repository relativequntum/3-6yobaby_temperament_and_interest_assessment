# 活动库 A3｜语言与读写萌发（Language & Emergent Literacy）

> 面向【中国家长】的【3–6 岁】「发展优势 + 兴趣画像」**非诊断**测评工具 · 循证活动库
> 版本：v1.0 ｜ 撰写日期：2026-06-03 ｜ 模块定位：**活动推荐素材库**（由分析 skill 按孩子的个体内画像挑选、裁剪后输出「游戏 / 锻炼 / 家庭陪伴」建议）
> 专题范围：亲子共读（对话式阅读）、讲故事 / 复述、词汇游戏、韵律儿歌、看图说话；含**双语家庭策略**。

---

## ⚠️ 使用与证据守则（务必前置）

1. **本库不是干预方案、不是治疗、不替代专业评估。** 活动用于「家庭日常陪伴与游戏」，帮助家长把孩子相对靠前/相对待支持的语言能力，转化为低成本、可操作的亲子活动。
2. **严禁编造效果声明。** 每条活动的 `evidence` 字段区分两档：
   - **【研究依据】**：有同行评审研究 / 权威机构（CDC、教育部、WHO、UNICEF）/ 成熟课程框架支撑的具体技术（如对话式阅读 PEER/CROWD、印刷指认、韵律觉知）。
   - **【一般性发展原理】**：方向正确、被广泛采用，但**无法挂到某条精确效应量研究**的常识性陪伴做法（如「指物命名」「丰富语言环境」）。本库**不把一般性原理伪装成研究**。
3. **效应量谨慎表述。** 共读/对话式阅读对口语词汇的效应在元分析中多为**小到中等**（表达性语言 d≈0.41、接受性语言 d≈0.26；Dowdall et al., 2020），且**受剂量调节**（读得太少几乎无效）。本库在 `evidence` 中如实写「小到中等效应、需持续」，不写「显著提升智力/包学会」。
4. **非诊断口径。** 任何活动都不用于判定孩子「语言落后/超常」。若家长在共读/对话中发现持续的理解或表达困难，应引导其咨询儿科 / 妇幼保健 / 言语治疗专业人员，而非用本库活动自我安慰。
5. **安全第一。** 每条含 `safety_notes`；凡涉及小物件（串珠、磁贴字卡）均提示窒息风险与看护。

## 0. 本域发展依据简述（为什么这些活动有用）

**口语是读写的根。** 3–6 岁是口语（尤其表达）快速发展期；口语词汇、叙事能力与音韵觉知共同构成「读写萌发（emergent literacy）」的基础，并预测后续正式阅读与书写（中国教育部《3–6 岁儿童学习与发展指南》语言领域分「倾听与表达」「阅读与书写准备」两条子领域；Storch & Whitehurst 的萌发读写双通路模型）。本库围绕四条有据可循的杠杆设计活动：

- **(1) 亲子共读 + 对话式阅读（dialogic reading）。** 由 Whitehurst 等开发的对话式阅读，用 **PEER**（Prompt 提问 → Evaluate 评价 → Expand 扩展 → Repeat 重复）与 **CROWD**（Completion 填空 / Recall 回忆 / Open-ended 开放 / Wh- 提问 / Distancing 联系生活）两套提示，把「大人念、孩子听」变成「孩子说、大人扩」。元分析显示共读对表达性/接受性语言有小到中等效应，且**家长共读技巧的改变效应很大**（d≈1.01，Dowdall et al., 2020），意味着「教会家长怎么读」是关键抓手；Reading Rockets 提示**回忆类、联系生活类提示更适合 4–5 岁及以上**。

- **(2) 讲故事 / 复述 / 看图说话 → 叙事能力。** 复述与讲故事训练能让孩子说出更长、结构更完整的故事，促进词汇、句子复杂度与「去情境化语言（decontextualized language，谈论不在眼前的过去/未来/想象）」；口语叙事能力是后续书面叙事结构、连贯与衔接的显著预测因子（Nicolopoulou et al., 2015；相关综述）。《指南》亦建议「鼓励幼儿依据画面线索讲述故事、大胆推测想象、续编/改编故事」。

- **(3) 去情境化对话 + 词汇游戏。** 家长多用**解释性与叙事性话语**（谈过去/未来、讲因果），孩子一年后词汇量更大（控制了输入总量与孩子先前词汇后仍成立；Rowe, 2012）。这是「质重于量」的语言输入原则。

- **(4) 韵律儿歌 → 音韵觉知（phonological awareness）。** 押韵觉知是 4 岁左右起测得的、对后续识字的标准预测变量；幼儿对儿歌/童谣的早期知识与其后续音韵与印刷相关技能相关（Maclean, Bryant & Bradley, 1987；Bryant et al., 1990）。儿歌天然练「音节切分、押韵、节奏」，是中文/英文都适用的低成本入口。**注意中文以「字—音节—声调」为单位，押韵与英文 onset-rime 不完全对应，本库中文音韵活动以「听辨押韵、数音节、绕口令/声调游戏」为主，不强行套用英文 phoneme 操作。**

- **(辅) 印刷指认与环境文字（print referencing / environmental print）。** 共读时大人偶尔指认字/标志、谈「这是字、从这边读起」，可提升印刷觉知（Justice & Ezell 印刷指认研究；环境文字干预对印刷/声音知识有中到大效应）。中文情境用招牌、绘本书名、孩子名字等做「环境文字」入口，**保持萌发取向，不提前进行机械识字/拼音教学**。

- **(双语) 双语家庭。** 孩子在某语言上的能力与其在该语言上的**输入量与质**密切相关（Hoff 等）；维持家庭少数语言需要**足量、稳定、高质量**的该语言输入。OPOL（一人一语）只是若干策略之一，**没有证据表明 OPOL 必然优于其他策略**——一致性与输入质量比「具体用哪种策略」更重要（Cambridge Applied Psycholinguistics 家庭语言模式研究；De Houwer）。本库双语活动强调「绘本/儿歌是高质量输入载体」「不混着教更不必焦虑偶尔混用」「读得开心比读得标准重要」。

> **对应本工具构念**：本库 `targets` 字段统一映射到工具既有构念键——发展领域 `DEV-COM`（沟通/语言）为主，旁及 `DEV-FM`（书写准备的精细动作）、`DEV-PS`（认知/叙事推理）、`DEV-PSE`（轮流/共情）；兴趣领域 `INT-LAN`（语言/故事偏好）、`INT-MUS`（音乐律动，对应儿歌）、`INT-SOC`（社交扮演，对应角色复述）；气质相关 `努力控制/注意聚焦`（专注听讲、轮流）、`负性情绪/慢热`（goodness-of-fit 调整见各条 `temperament_fit_notes`）。

### A3-01 对话式阅读·PEER 基础轮（把念书变成对话）
- **name**：对话式阅读 PEER 一轮（提问—评价—扩展—重复）
- **type**：companionship / game
- **domain**：亲子共读（对话式阅读）
- **targets**：`DEV-COM`（表达性词汇、对话来回）、`INT-LAN`（语言/故事兴趣）、`努力控制·注意聚焦`（专注听讲）
- **age_bands**：3-4 / 4-5 / 5-6
- **materials**：任意有图画的绘本（图书馆借/家中现有即可）
- **steps**：
  1. 选一本孩子喜欢的绘本，读一两页后停下。
  2. **P 提问**：指着画面问一个问题（「这是什么？」「他在干嘛？」）。
  3. **E 评价**：孩子答对就肯定（「对，是小狗！」）；答不全不纠错责备。
  4. **E 扩展**：把孩子的话扩长（孩子说「狗」→你说「对，一只毛茸茸的大狗在跑」）。
  5. **R 重复**：把扩展后的句子让孩子再说一遍，再翻下一页。
- **difficulty_ladder**：更易：只做「指物—命名—重复」，不要求成句；更难：一页问 2–3 个不同类型问题，鼓励孩子用完整句子回答。
- **temperament_fit_notes**：**慢热/高负性情绪**：先让孩子主导翻页、你少提问，等熟悉后再加问题，避免「被考」压力；**高活跃**：选短篇、互动翻翻书，允许边读边比划，单次 5–8 分钟即可，频次高于时长。
- **evidence**：【研究依据】对话式阅读（Whitehurst 等）PEER 框架；共读对表达/接受性语言小到中等效应、对家长共读技巧大效应（Dowdall et al., 2020 元分析）。
- **safety_notes**：低龄选圆角/布书/硬卡书，避免纸边割手；共读环境光线充足、坐姿舒适。

### A3-02 CROWD 五问轮换（给绘本配五种问题）
- **name**：CROWD 提问轮换（填空/回忆/开放/Wh/联系生活）
- **type**：companionship / game
- **domain**：亲子共读（对话式阅读）
- **targets**：`DEV-COM`（理解+表达、问答来回）、`DEV-PS`（回忆/推理、预测情节）、`INT-LAN`
- **age_bands**：3-4（以 C/O/Wh 为主）/ 4-5 / 5-6（加 R/D）
- **materials**：熟悉的绘本（读过几遍的最好）
- **steps**：
  1. **C 填空**：读到押韵/重复句时停住让孩子接（「我才不要这么……（胖）」）。
  2. **R 回忆**：读完问「小蓝火车后来怎么了？」
  3. **O 开放**：指一张细节多的图说「跟我讲讲这页发生了什么」。
  4. **Wh 提问**：用「什么/哪里/为什么/怎么」问，引入新词。
  5. **D 联系生活**：「记得我们上次去动物园看到哪些动物？」
- **difficulty_ladder**：更易：每次只用 1–2 种问题（3–4 岁先用填空+Wh）；更难：5–6 岁让孩子反过来出问题考你。
- **temperament_fit_notes**：**回忆类(R)与联系生活类(D)对 4–5 岁及以上更合适**（Reading Rockets），对 3 岁孩子以填空/开放/Wh 为主，避免超出能力的「为什么」连环问引发挫败；**高负性情绪**孩子答不出时立刻降级到填空题给成功体验。
- **evidence**：【研究依据】CROWD 提示框架（对话式阅读）；R/D 适用 4–5 岁起（Reading Rockets 综述对话式阅读条目）。
- **safety_notes**：同 A3-01。

### A3-03 看图说话·一页一句到一段
- **name**：看图说话（依画面线索讲述）
- **type**：game / companionship
- **domain**：看图说话 / 叙事
- **targets**：`DEV-COM`（看图描述、句子加长）、`INT-LAN`、`DEV-PS`（观察推理）
- **age_bands**：3-4 / 4-5 / 5-6
- **materials**：无字书 / 图多字少的绘本 / 家庭照片
- **steps**：
  1. 选一页画面丰富的图，先让孩子自由说「你看到了什么」。
  2. 你示范用一个稍长的句子描述（带地点/动作/心情）。
  3. 引导孩子说出「谁、在哪、做什么、心情怎样」。
  4. 翻几页后，请孩子把几页连起来「讲成一个小故事」。
- **difficulty_ladder**：更易：一页只说一个词或一个短句；更难：要求加入「开头—中间—结尾」并解释角色为什么这么做。
- **temperament_fit_notes**：**慢热**：从家庭照片这类熟悉内容开始更容易开口；**高活跃**：可让孩子边演边说（动作辅助语言），不强求安静坐着。
- **evidence**：【研究依据】《3–6 岁儿童学习与发展指南》建议「依据画面线索讲述、推测想象」；看图/叙事促进口语与去情境化语言（叙事能力研究）。【一般性发展原理】「谁在哪做什么」的框架为常用教学支架。
- **safety_notes**：照片/绘本无特殊风险；注意不强迫表达，保护开口意愿。

### A3-04 故事复述·三幕骨架
- **name**：故事复述（听完讲回来）
- **type**：game / companionship
- **domain**：讲故事 / 复述
- **targets**：`DEV-COM`（复述、≥2 情节叙事）、`DEV-PS`（记忆/排序）、`努力控制·注意聚焦`
- **age_bands**：4-5（简短）/ 5-6（含≥2 情节、有先后）
- **materials**：一本短故事绘本
- **steps**：
  1. 完整读一遍短故事。
  2. 用「开头发生了什么？→ 然后呢？→ 最后怎样？」三问搭骨架。
  3. 请孩子用自己的话从头讲一遍，你只在卡住时给关键词提示。
  4. 可让孩子讲给另一位家人/玩偶听，增加真实听众。
- **difficulty_ladder**：更易：先做「填空式复述」（你讲大半、孩子补关键词）；更难：复述后请孩子「续编一个不同的结尾」。
- **temperament_fit_notes**：**高负性情绪/怕错**：强调「怎么讲都行，这是你的版本」，不纠正细节出入；**高活跃**：允许用玩偶/动作演出来代替纯口述。
- **evidence**：【研究依据】复述指导可让孩子产出更长、结构更完整的故事，促进词汇与去情境化语言；口语叙事预测后续书面叙事结构（叙事能力研究综述）。
- **safety_notes**：无特殊风险；玩偶等道具检查无小零件脱落。

### A3-05 「今天发生了什么」餐桌叙事
- **name**：每日叙事（讲一件今天的事）
- **type**：companionship
- **domain**：去情境化语言 / 叙事
- **targets**：`DEV-COM`（讲清来龙去脉、当天事件叙述）、`DEV-PS`（时间词/因果）、`DEV-PSE`（轮流交谈）
- **age_bands**：4-5 / 5-6
- **materials**：无（利用吃饭/睡前时间）
- **steps**：
  1. 固定一个时段（晚餐或睡前），轮流讲「今天一件事」。
  2. 大人先示范，讲清「在哪、和谁、发生了什么、我感觉怎样」。
  3. 用开放问题追问细节（「然后呢？」「你为什么开心？」）。
  4. 偶尔聊「明天打算做什么」，练将来时间词。
- **difficulty_ladder**：更易：用「好的事/不太好的事」各一件做提示；更难：要求按时间顺序讲三件事并加因果连接（「因为…所以…」）。
- **temperament_fit_notes**：**慢热/内向**：先让孩子听大人讲、不强制每天开口，营造放松氛围；**高负性情绪**：聚焦正向事件起步，避免变成「盘问当天表现」。
- **evidence**：【研究依据】家长多用解释性/叙事性话语（谈过去未来、讲因果），孩子一年后词汇量更大（Rowe, 2012 去情境化语言研究）。
- **safety_notes**：无；保持轻松，避免演变为批评孩子的场合。

### A3-06 押韵接龙·儿歌找朋友
- **name**：押韵游戏（找押韵的词）
- **type**：game
- **domain**：韵律儿歌 / 音韵觉知
- **targets**：`DEV-COM`（音韵觉知·押韵听辨）、`INT-MUS`（律动/儿歌兴趣）、`INT-LAN`
- **age_bands**：4-5 / 5-6（押韵觉知约 4 岁起可测）
- **materials**：无（可借熟悉儿歌）
- **steps**：
  1. 先念一首押韵儿歌，强调结尾押韵的字。
  2. 玩「找朋友」：你说一个字，孩子找一个尾音相同/相近的字（猫—包—跑…，中文以韵母相近为主）。
  3. 编简单两句顺口溜，让孩子补上押韵的尾字。
- **difficulty_ladder**：更易：你给两个词让孩子判断「押不押韵」（听辨先于产出）；更难：让孩子自己想出三个押韵词，或编一句完整押韵句。
- **temperament_fit_notes**：**高活跃**：配合拍手/跺脚打节奏，把听辨变成动起来的游戏；**慢热**：先只听不答，多听几遍再邀请参与。
- **evidence**：【研究依据】押韵觉知约 4 岁起为后续识字的标准预测变量；幼儿儿歌知识与音韵/印刷技能相关（Maclean, Bryant & Bradley, 1987；Bryant et al., 1990）。注：中文以韵母/音节为单位，与英文 onset-rime 不完全对应。
- **safety_notes**：纯口头游戏，无风险。

### A3-07 儿歌律动·边唱边做
- **name**：童谣儿歌律动（唱+动作）
- **type**：game / exercise
- **domain**：韵律儿歌
- **targets**：`INT-MUS`（音乐律动兴趣）、`DEV-COM`（节奏/音节、词句记忆）、`DEV-GM`（大动作配合，轻度）
- **age_bands**：3-4 / 4-5 / 5-6
- **materials**：常见中文童谣（《小星星》《两只老虎》《数鸭子》等），可选无伴奏
- **steps**：
  1. 选一首短童谣，先慢速唱一遍，配简单手势动作。
  2. 鼓励孩子跟唱跟做，重点在「跟上节奏、记住词句」。
  3. 玩「停一下接一句」：唱到熟句停住让孩子接（填空式）。
- **difficulty_ladder**：更易：只跟做动作、哼旋律，不要求唱准词；更难：加快速度，或换词改编（把「老虎」换成孩子喜欢的动物）。
- **temperament_fit_notes**：**高活跃**：这是消耗精力又练语言的好活动，可加大动作幅度；**慢热**：父母先唱给孩子听，不催促开口，孩子常会先在心里记熟再唱出来。
- **evidence**：【研究依据】儿歌/童谣经验与音韵觉知、词汇相关（Maclean et al., 1987）。【一般性发展原理】律动配合有助记忆与参与（多通道学习的通行经验）。
- **safety_notes**：动作类避免在硬地/狭窄处剧烈摆动，留出空间防碰撞。

### A3-08 绕口令·声调与发音游戏（中文特色）
- **name**：绕口令小挑战
- **type**：game
- **domain**：韵律 / 音韵觉知（中文声调）
- **targets**：`DEV-COM`（发音清晰度、音节觉知）、`INT-LAN`
- **age_bands**：5-6（短句，量力）
- **materials**：简单绕口令（「四是四，十是十」简化版）
- **steps**：
  1. 慢速念一句短绕口令，逐字清晰。
  2. 让孩子跟念，重在「念清楚」而非「念快」。
  3. 比赛谁念得清，偶尔故意念错让孩子纠正（增强觉知）。
- **difficulty_ladder**：更易：只念三四个字的小段；更难：逐渐加长或略加速。
- **temperament_fit_notes**：**高负性情绪/完美主义**：明确「念错很好玩」，把出错变成笑点而非失败；**慢热**：私下先练，不在众人前要求表演。
- **evidence**：【一般性发展原理】绕口令练发音与音节/声调觉知，方向与音韵觉知一致；**无针对效应量的精确研究背书，列为原理性**。
- **safety_notes**：纯口头，无风险；避免因「念不好」施压。

### A3-09 印刷指认·共读时摸字
- **name**：共读印刷指认（指字、谈「这是字」）
- **type**：companionship / game
- **domain**：印刷觉知 / 读写萌发
- **targets**：`DEV-COM`（印刷觉知、文字功能）、`DEV-PS`（符号—意义对应）、`INT-LAN`
- **age_bands**：4-5 / 5-6
- **materials**：字较大、版式清晰的绘本
- **steps**：
  1. 共读时偶尔用手指顺着文字移动，告诉孩子「我们从这边读到这边」。
  2. 指认书名、反复出现的字（如孩子名字里的字）。
  3. 玩「找一找」：让孩子在页面上找出某个见过的字/标志。
- **difficulty_ladder**：更易：只指书名和图，不要求认字；更难：找出同一个字在不同页出现几次。
- **temperament_fit_notes**：**高活跃**：把「找字」做成寻宝游戏，限时找一个就翻页；通用：**保持萌发取向，不变成机械认字课**，孩子主导兴趣为先。
- **evidence**：【研究依据】共读中印刷指认（点字、谈文字功能）提升印刷觉知；环境文字干预对印刷/声音知识中到大效应（印刷指认与环境文字研究）。
- **safety_notes**：无；避免把共读变成识字考核而扼杀阅读兴趣。

### A3-10 环境文字寻宝（招牌、包装上的字）
- **name**：生活中找字（环境文字）
- **type**：game / exercise（户外走动）
- **domain**：环境文字 / 读写萌发
- **targets**：`DEV-COM`（印刷觉知、文字—意义联系）、`INT-LAN`、`INT-NAT`（户外观察，旁及）
- **age_bands**：3-4（认标志）/ 4-5 / 5-6（认字）
- **materials**：户外招牌、食品包装、电梯按钮数字等（零成本）
- **steps**：
  1. 散步或购物时，指着招牌/包装问「这上面写的是什么？」
  2. 从孩子熟悉的标志起步（常去店铺 logo、自己名字、数字）。
  3. 回家把包装上的字剪下来贴成「我认识的字」墙。

- **evidence**：【研究依据】环境文字（低成本材料）对印刷知识、声音知识、印刷觉知有中到大效应（环境文字干预研究）。
- **safety_notes**：户外注意交通与人流安全，认字让位于看路；剪贴用圆头剪刀并看护。

### A3-11 词汇游戏·分类与命名
- **name**：词汇分类游戏（这是哪一类）
- **type**：game
- **domain**：词汇游戏
- **targets**：`DEV-COM`（词汇广度/类别词）、`DEV-PS`（分类/概念）、`INT-LOG`（分类逻辑，旁及）
- **age_bands**：3-4 / 4-5 / 5-6
- **materials**：家中物品、玩具、卡片或绘本图
- **steps**：
  1. 摆几样东西，玩「都是吃的/都是会跑的」找同类。
  2. 给上位词命名（「苹果、香蕉、橘子都是……水果」）。
  3. 反向玩：你说类别，孩子举例（「说三种水果」）。

- **safety_notes**：小物件/卡片防误吞，3 岁以下或爱放嘴里的孩子用大件物品。

### A3-12 新词「丰富解释」三件套
- **name**：新词慢镜头（解释+举例+用一用）
- **type**：companionship
- **domain**：词汇游戏 / 去情境化语言
- **targets**：`DEV-COM`（词汇深度、解释性语言）、`DEV-PS`（概念理解）
- **age_bands**：4-5 / 5-6
- **materials**：日常对话/绘本中冒出的新词
- **steps**：
  1. 遇到新词，先用孩子懂的话**解释**（「『犹豫』就是拿不定主意」）。
  2. 给一个生活**例子**（「你选冰淇淋口味时犹豫了好久」）。
  3. 当天找机会**再用一次**这个词，请孩子也用一次。
- **difficulty_ladder**：更易：每天只「精讲」一个新词；更难：一周收集 3–5 个新词做「我们的新词本」（画图/口头复习）。
- **temperament_fit_notes**：通用——**质重于量**，与其塞很多词，不如把一两个词讲透、反复用；**高负性情绪**孩子不要测验式抽查。
- **evidence**：【研究依据】解释性话语预测更大词汇量（Rowe, 2012）；【一般性发展原理】「解释—举例—再用」为常用词汇深度教学法。
- **safety_notes**：无。

### A3-13 「为什么/如果」开放对话
- **name**：开放式追问对话（为什么·如果·你觉得呢）
- **type**：companionship
- **domain**：去情境化语言 / 对话
- **targets**：`DEV-COM`（对话来回、推理性表达）、`DEV-PS`（因果/假设推理）、`努力控制`（轮流听说）
- **age_bands**：4-5 / 5-6
- **materials**：无（任何日常情境）
- **steps**：
  1. 在散步、做饭等场景抛一个开放问题（「你觉得乌云为什么变黑？」）。
  2. 用「如果……会怎样？」激发假设（「如果鱼会飞会怎样？」）。
  3. 认真倾听、追问，不急于给「正确答案」。
- **difficulty_ladder**：更易：从「你喜欢哪个、为什么」这类二选一加理由开始；更难：就一个话题来回 3 个以上回合并请孩子反问你。
- **temperament_fit_notes**：**慢热**：给足思考时间（沉默 5–10 秒别急着替他说）；**高活跃**：在动起来时聊（边走边问）比强制坐谈更易投入。
- **evidence**：【研究依据】保持多回合对话、用 Wh/假设问题是去情境化语言与对话发展的核心；与工具 `DEV-COM` 锚点「≥3 回合对话」一致（CDC 2022）。
- **safety_notes**：无；尊重孩子「不想聊」的时刻。

### A3-14 角色扮演复述（演绘本）
- **name**：把绘本演出来（戏剧化复述）
- **type**：game / companionship
- **domain**：讲故事 / 复述（扮演）
- **targets**：`DEV-COM`（叙事、对话语言）、`INT-SOC`（社交扮演兴趣）、`DEV-PSE`（角色轮流/共情）
- **age_bands**：3-4（简单角色）/ 4-5 / 5-6
- **materials**：读过的绘本 + 家中道具（毛巾当披风、玩偶当角色）
- **steps**：
  1. 选一个情节简单的故事，分配角色（你和孩子各演一个）。
  2. 边演边说角色台词，按故事顺序走一遍。
  3. 鼓励孩子加入自己的台词或改一个情节。
- **difficulty_ladder**：更易：只演一个动作场景，配一两句台词；更难：完整演出含开头—冲突—结尾，并互换角色再演。
- **temperament_fit_notes**：**高活跃**：扮演是把精力导入语言的极佳出口；**慢热/害羞**：先演给玩偶看、不要求面对众人，父母多承担「话多」的角色降低压力。
- **evidence**：【研究依据】故事扮演（storytelling/story-acting）与叙事理解、印刷与词汇觉知、自我调节相关（Nicolopoulou et al., 2015）。
- **safety_notes**：道具避免长绳/塑料袋等缠绕窒息风险；演出空间清空防绊倒。

### A3-15 自制小书 / 口述我画
- **name**：自制故事小书（孩子口述、家长记录）
- **type**：game / companionship
- **domain**：读写萌发（书写准备）/ 叙事
- **targets**：`DEV-COM`（叙事、口语转文字概念）、`DEV-FM`（涂画/握笔，书写准备）、`INT-ART`（绘画兴趣，旁及）
- **age_bands**：4-5 / 5-6
- **materials**：几张纸订成小册、蜡笔/彩笔
- **steps**：
  1. 让孩子画一个简单故事（每页一个画面）。
  2. 孩子口述每页发生什么，家长把孩子的话**原样**写在画下面。
  3. 读回给孩子听，让他知道「我说的话变成了字」。
- **difficulty_ladder**：更易：只画+口述一页；更难：做三页以上、有开头中间结尾，孩子尝试写标题或自己名字。
- **temperament_fit_notes**：**高负性情绪/怕画不好**：强调「你画的就是最好的」，重过程不重像不像；**高活跃**：限定页数、配合站着画/趴地上画。
- **evidence**：【研究依据】口语叙事是后续书面叙事的预测因子（叙事能力研究）；「口述—家长记录」体现「话可以变成字」的印刷概念。【一般性发展原理】涂画为握笔/书写准备（与工具 `DEV-FM` 锚点一致）。
- **safety_notes**：蜡笔选无毒、大号防误吞；订书针由家长操作并收好。

### A3-16 重复阅读·最爱的书读三遍
- **name**：重复共读同一本书
- **type**：companionship
- **domain**：亲子共读
- **targets**：`DEV-COM`（词汇巩固、预期句式）、`INT-LAN`（再投入/个体兴趣信号）、`努力控制`
- **age_bands**：3-4 / 4-5 / 5-6
- **materials**：孩子最爱的一两本绘本
- **steps**：
  1. 同一本书在几天内反复读，每遍换一个重点。
  2. 第一遍享受故事；第二遍多问 CROWD 问题；第三遍让孩子带你读/接句。
  3. 留意孩子能预测/接出的句子越来越多。
- **difficulty_ladder**：更易：只重复读、孩子接熟悉的填空；更难：读到熟后让孩子「当老师」读给你听并解释。
- **temperament_fit_notes**：**慢热**：重复带来的熟悉感特别能降低焦虑、增加主动开口；通用：孩子反复要求读同一本是**正常且有益**的（再投入＝兴趣加深信号），不必嫌烦换书。
- **evidence**：【研究依据】重复共读支持词汇巩固与参与；反复「再投入」对应兴趣四阶段中个体兴趣的加深（Hidi & Renninger, 2006，工具 `INT` 体系）。【一般性发展原理】熟悉性提升预测与参与。
- **safety_notes**：同 A3-01。

### A3-17 双语共读·一本书两种语言（双语家庭）
- **name**：双语亲子共读（绘本作高质量输入）
- **type**：companionship
- **domain**：亲子共读 / 双语策略
- **targets**：`DEV-COM`（双语词汇/理解）、`INT-LAN`、`FAM·双语输入质量`
- **age_bands**：3-4 / 4-5 / 5-6
- **materials**：少数语言（或第二语言）的绘本 / 双语绘本
- **steps**：
  1. 选孩子喜欢的故事，用**目标语言**读一遍（家长说哪种语言，就稳定用那种读）。
  2. 用对话式阅读 PEER 在目标语言里提问扩展。
  3. 若孩子不懂某词，可短暂用母语解释后回到目标语言，不必逐句翻译。
- **difficulty_ladder**：更易：先读图、用目标语言只说关键词；更难：整本用目标语言共读并复述。
- **temperament_fit_notes**：通用——**读得开心、输入足量稳定比「说得标准」更重要**；**慢热/对第二语言抵触**：从最爱的故事和儿歌入手，降低「学外语」的压力感。
- **evidence**：【研究依据】孩子某语言能力与该语言**输入量与质**相关；维持家庭少数语言需足量稳定高质量输入（Hoff 等）；绘本共读对双语儿童第二语言有显著效应（d≈.25–.66，Grøver et al., 2020）。
- **safety_notes**：同共读；避免因纠正发音/语法过度而打击表达意愿。

### A3-18 双语策略·一致性优先（家庭语言计划）
- **name**：家庭双语策略（OPOL 或场景分语，重在一致）
- **type**：companionship
- **domain**：双语策略
- **targets**：`FAM·双语输入一致性`、`DEV-COM`（两种语言均衡发展）
- **age_bands**：3-4 / 4-5 / 5-6（越早建立越易坚持）
- **materials**：无（家庭约定）
- **steps**：
  1. 全家商定一个**可持续**的规则：如「妈妈说 A 语、爸爸说 B 语」（OPOL），或「在家说少数语、在外说主流语」（场景分语）。
  2. 关键是**稳定执行**，并为少数语言安排足量场景（绘本、儿歌、视频、亲友）。
  3. 偶尔混用很正常，不必焦虑或当众纠正孩子。
- **difficulty_ladder**：更易：先保证「每天有固定的少数语言时段」（如睡前共读全用少数语）；更难：扩展到玩伴/社群，给少数语言真实使用场合。
- **temperament_fit_notes**：通用——孩子**慢热或一度只说主流语是常见阶段**，保持输入、不施压，常会在准备好时输出；避免把语言变成考核。
- **evidence**：【研究依据】输入量与质决定双语能力；**无证据表明 OPOL 必然优于其他策略**，一致性与输入质量比具体策略更重要（家庭语言模式研究；De Houwer；Hoff）。
- **safety_notes**：无；避免家庭因语言要求产生紧张氛围影响亲子关系。

### A3-19 听指令做动作（听理解游戏）
- **name**：听口令做动作（西蒙说·中文版）
- **type**：game / exercise
- **domain**：倾听理解
- **targets**：`DEV-COM`（听理解、多步指令）、`努力控制·抑制控制`（西蒙说需抑制）、`DEV-GM`（大动作，旁及）

### A3-20 命名指物·日常旁白（低龄/慢热友好）
- **name**：生活旁白与指物命名
- **type**：companionship
- **domain**：词汇 / 倾听表达
- **targets**：`DEV-COM`（词汇输入量、命名）、`INT-LAN`
- **age_bands**：3-4（核心）/ 4-5
- **materials**：无（日常起居）
- **steps**：

  2. 指认眼前事物并命名，停顿等孩子跟说。
  3. 把孩子指/看的东西命名并扩展一句。
- **difficulty_ladder**：更易：只命名单词；更难：旁白时加入因果与顺序词（先…然后…因为…）。
- **temperament_fit_notes**：**慢热/语言起步晚**：旁白提供无压力的丰富输入，孩子不需回应也在吸收；**高活跃**：在他正做的事情上旁白（跟随兴趣）比拉回来教更有效。
- **evidence**：【一般性发展原理】丰富、回应式的语言输入支持词汇发展（输入量与质原则，方向同 Hoff/Rowe）；**指物命名本身为常识性陪伴，列为原理性**。
- **safety_notes**：无。

---

### A3-21 图书馆 / 绘本馆习惯（陪伴+兴趣）
- **name**：定期逛图书馆 / 借书仪式
- **type**：companionship / exercise（外出）
- **domain**：亲子共读 / 阅读兴趣
- **targets**：`INT-LAN`（语言/故事兴趣、自主选择）、`DEV-COM`、`DEV-PSE`（公共场合行为调整）
- **age_bands**：3-4 / 4-5 / 5-6
- **materials**：社区图书馆 / 绘本馆借书卡（低成本/免费）
- **steps**：
  1. 固定频率（如每两周）带孩子去借书。
  2. 让孩子**自主选**几本（培养个体兴趣与自主发起）。
  3. 回家把新书纳入共读，读完一起还书、再选。
- **difficulty_ladder**：更易：每次只借一两本、读完即可；更难：让孩子按主题选（「这次找关于海洋的书」）并说说为什么选。
- **temperament_fit_notes**：**高活跃**：先在儿童区动一动再选书，约定「轻声」规则（练场合行为，对应 `DEV-PSE`）；**慢热**：熟悉环境需要几次，前几次只看不借也可。
- **evidence**：【研究依据】自主选择支持个体兴趣发展（兴趣四阶段，工具 `INT`）；图书可及性是共读频率的前提。【一般性发展原理】阅读习惯/仪式感培养长期阅读兴趣。
- **safety_notes**：外出注意看护；公共场所手部卫生。

---

### A3-22 「我说你猜」描述游戏
- **name**：描述猜词游戏（不说名字描述它）
- **type**：game
- **domain**：词汇 / 表达
- **targets**：`DEV-COM`（描述性表达、特征词）、`DEV-PS`（特征推理）、`INT-LAN`
- **age_bands**：4-5 / 5-6
- **materials**：无（或一袋小物/卡片）
- **steps**：
  1. 你描述一样东西的特征（「圆圆的、会滚、能踢」），孩子猜（球）。
  2. 互换角色，让孩子描述、你来猜（练表达）。
  3. 逐步要求多说几个特征再猜。
- **difficulty_ladder**：更易：描述眼前能看到的东西；更难：描述抽象/看不见的东西（去情境化，如「开心」「昨天」）。
- **temperament_fit_notes**：**慢热**：先由你描述、孩子只需猜（接受性先于表达性）；**高负性情绪**：猜不中时给更多线索，确保有成功体验。
- **evidence**：【一般性发展原理】描述游戏练特征词与去情境化表达，方向与词汇深度/去情境化语言一致（Rowe 原则）；具体玩法为常用语言游戏，**列为原理性**。
- **safety_notes**：小物件防误吞，看护下使用。
