# 循证活动库 A6：学习品质（Approaches to Learning）

> 面向【中国家长】的 3–6 岁「发展优势 + 兴趣画像」**非诊断**测评工具配套活动库
> 用途：由分析 skill 按孩子的**个体内画像**（哪几个 LRN 子维度是相对优势 / 相对待发展）挑选并裁剪，输出「游戏 / 锻炼 / 家庭陪伴」建议。
> 本专题 = 学习品质培养：好奇探索、专注与坚持、掌握动机与抗挫、创造灵活。
> 编制日期：2026-06-03 ｜ 编者：儿童发展 / 早期教育专家
>
> 【铁律·与测评工具一致】
> 1. **不编造效果声明**：每条活动写清「练什么（对应本工具构念 / 能力）」与「依据」。依据来自同行评审 / 权威机构 / 课程框架者标来源；仅有一般共识者，明确标注为**「一般性发展原理」**，绝不伪造研究。
> 2. **非诊断、个体内定位**：活动是「顺势养育 / 创造机会」的建议，**不是干预处方**，不承诺提高某分数、不做能力达标判定。
> 3. **气质匹配（goodness-of-fit）**：每条给出对高活跃 / 慢热 / 高负性情绪等不同气质的调整，体现 Thomas & Chess 的匹配观。
> 4. **安全与可操作**：适合中国家庭（常见材料、居家 / 户外、低成本），列安全注意。

## 0. 与测评工具构念的对接（targets 词表）

本活动库的 `targets` 字段严格对齐 `docs/research/05-approaches-to-learning.md §4` 的 6 个可计分子维度，便于分析 skill 按个体内画像精确匹配：

| key | 子维度（中文） | 对应 | 该维度高分孩子→顺势 / 低分孩子→创造机会 |
|---|---|---|---|
| **LRN-A** | 专注与坚持 | DMQ 认知 / 大动作坚持 + EF（注意 / 抗干扰 / 工作记忆） | 高→给更长时程、有步骤的挑战；低→拆小步骤、缩短时段、减少干扰源 |
| **LRN-B** | 好奇与探索 | I/D-YC 认识性好奇 + Jirout 探索性好奇 + ELOF P-ATL 11 | 高→多给开放式材料与「为什么」；低→从其已有兴趣点切入、降低新奇度 |
| **LRN-C** | 主动性与自我驱动 | ELOF P-ATL 10 + DMQ 社会性坚持（与成人 / 同伴） | 高→给选择权与发起空间；低→给「二选一」式有限选择、成人先示范再退场 |
| **LRN-D** | 创造与灵活 | ELOF P-ATL 12 + EF 认知灵活 / 转换 | 高→开放材料、变规则；低→先固定玩法熟练后再引入「换个法子」 |
| **LRN-E** | 掌握愉悦与挑战取向 | DMQ 掌握愉悦 + 成长型思维前体（寻求挑战） | 高→提供「跳一跳够得着」的中等挑战；低→先在易任务上积累成功体验 |
| **LRN-F** | 面对挫折的恢复（成长前体） | DMQ 负性反应（反向）+ Gunderson / Dweck 过程取向 | 高（恢复好）→可适度增加挑战；低（易受挫）→情绪共情 + 拆步 + 过程表扬 |

> 跨域提示：学习品质活动天然牵动**精细 / 大动作、语言、努力控制 / 情绪调节**等其他域；`domain` 标「学习品质（ATL）」为主，跨域能力在 `targets` 末尾以括注列出，方便分析 skill 做跨画像组合。

## 1. 该域发展依据（简述）

**学习品质（ATL）= 孩子「如何学」而非「学了多少」**：好奇、主动、专注、坚持、灵活、创造等学习倾向（dispositions），是被广泛认可却常被低估的「入学准备」领域（Hyson 2008；Head Start ELOF）。其与发展心理学的**掌握动机**（White 1959 的胜任 / effectance 动机 → Morgan 等 DMQ 体系）高度交叠：在「对孩子而言中等难度」的任务上专注而坚持地尝试掌握，是内在驱力的核心表现，并伴随**掌握愉悦**与**面对挑战的情绪反应**两类情感（DMQ 18）。

落到「怎么养」，本活动库依据以下相对扎实的循证主线：

1. **引导式游戏（guided play）优于纯自由游戏 / 直接灌输**：Skene et al.(2022) 对 39 项研究、17 项进入元分析（约 3,893 名 1–8 岁儿童）做系统综述，发现引导式游戏在**空间词汇**上优于自由游戏（g≈0.93），在**早期数学、形状知识、任务切换**上优于直接灌输（g≈0.24–0.63）。这支持「成人在场、跟随孩子兴趣、用开放式提问轻推」这一活动设计原则（对应 LRN-B/D）。
2. **开放式提问与对话式共读促进投入、语言与思维**：对话式阅读（Whitehurst 等 1988）是被反复验证的早期读写干预，对儿童语言有中—大效应，并对注意、社会情绪有更广益处（WWC；多项 RCT 与元分析）。开放式提问（「你觉得接下来会怎样？」「还能怎么玩？」）能拉伸好奇、推理与表达（权威育儿 / 教学机构共识 + 共读证据外推）（对应 LRN-B/D/C）。
3. **建构 / 积木游戏与早期 EF、空间、数学相关**：多项研究（含 RCT）显示积木 / 拼搭与执行功能（尤其行为自我调节、任务切换）、空间与早期数学相关，早期积木参与可预测后续数学（Schmitt et al.；Verdine et al. 等）（对应 LRN-A/D）。
4. **假装 / 社会戏剧游戏与发散思维、认知灵活相关**：假装游戏与想象力、流畅性、问题解决、认知灵活相关；但因果证据仍有争议（Lillard et al. 2013 的批评性综述指出部分声称被夸大），故本库措辞为「相关 / 提供练习机会」而非「提升创造力」（对应 LRN-D）。
5. **过程表扬（表扬努力 / 策略）→ 成长型动机框架前体**：Gunderson et al.(2013) 纵向发现 1–3 岁时父母过程表扬比例越高，孩子约 7–8 岁时越倾向增量 / 成长动机框架并更想要挑战；实验室研究显示对 4–6 岁也能用过程 vs 个人表扬影响掌握 vs 无助取向（Kamins & Dweck 1999）。**注意：Gunderson 原文未测学业成就，故本库不宣称「提高成绩」**（对应 LRN-E/F）。
6. **成人的自主支持 vs 侵入 / 包办**：观察研究显示父母**自主支持**与幼儿在挑战任务上的坚持正相关，而**侵入 / 强控制**与坚持负相关。故许多活动的核心是成人「**不打断、不代劳、忍住手**」（对应 LRN-A/C/E/F）。
7. **适度挑战（中等难度最优）与心流**：掌握动机定义强调「中等难度」最能激发投入；难度阶梯（difficulty_ladder）即为此设计——太易则无聊、太难则放弃（DMQ_def；Csikszentmihalyi 心流思想，作为框架性原理）。

> 证据强度分级（用于 evidence 字段）：
> 🟢 **较强**＝有同行评审 RCT / 元分析 / 系统综述直接支持该「活动类别→能力」链条；
> 🟡 **中等**＝相关研究或权威框架支持，因果仍有限 / 有争议；
> ⚪ **一般性发展原理**＝专业共识 / 框架建议，无针对该具体玩法的实验证据，**据实标注、不伪造**。

## 2. 候选活动库（24 条，覆盖三段 × game/exercise/companionship）

### A 组 · 好奇与探索（主练 LRN-B，多牵 LRN-C/D）

---

**A6-01 「这是什么」探索盒（神秘袋 / 自然百宝盒）**
- type: game, companionship
- domain: 学习品质（ATL）
- targets: LRN-B 好奇与探索（主）、LRN-D 创造与灵活、（跨域：语言-词汇、精细动作-触觉辨认）
- age_bands: 3-4, 4-5, 5-6
- materials: 一个布袋 / 鞋盒；家里或散步捡的安全小物（松果、贝壳、勺子、毛球、橡皮、积木块等，3–6 件）
- steps:
  1. 把几件小物装进不透明袋子。
  2. 孩子伸手摸（先不看），描述「滑滑的 / 有尖尖的 / 凉凉的」，猜是什么。
  3. 拿出来看，问开放式问题：「它还能怎么用？」「你在哪儿还见过像这样的东西？」
  4. 让孩子也藏几样考大人，角色互换。
- difficulty_ladder: 更易—先看得见地摸、只放 2–3 件高对比的物；更难—只凭触觉描述并分类（「按软硬 / 大小分两堆」），或加入「它属于厨房还是户外」的归类追问。
- temperament_fit_notes: 高活跃—缩短为 2–3 件、可站着玩、轮流快节奏；慢热 / 害羞—大人先示范摸并自言自语，给孩子观望时间，不催；高负性情绪—避免「猜错」氛围，强调「猜什么都行」，不计分。
- evidence: 🟡 跟随兴趣的探索 + 成人开放式提问符合引导式游戏优于纯自由 / 灌输的元分析结论（Skene et al. 2022）；触觉探索与「主动靠近、去看去摸弄清楚」对应 I/D-YC 的 I 型好奇行为锚点（Tang et al. 2024）。开放式提问拉伸好奇与语言为教学机构共识（⚪ 一般性发展原理 + 共读证据外推）。
- safety_notes: 3–4 岁严防误吞，所有小物须大于幼儿口腔（直径 > 约 3.2 cm 或用「卷纸筒测试」）；不放尖锐 / 易碎 / 电池纽扣；散步捡拾后先洗手。

---

**A6-02 「为什么会这样」厨房小实验（沉浮 / 溶解 / 颜色混合）**
- type: game, companionship
- domain: 学习品质（ATL）
- targets: LRN-B 好奇与探索（主）、LRN-E 掌握愉悦与挑战取向、（跨域：科学探究-观察预测、语言）
- age_bands: 4-5, 5-6（3-4 可做简化版「看颜色混」）
- materials: 透明杯 / 盆、水、若干小物（葡萄、勺子、塑料盖、积木）、食用色素或可食颜料、盐 / 糖
- steps:
  1. 玩「预测—试验」：拿一样东西，先问「你猜它会浮还是沉？」让孩子说出猜测。
  2. 放进水里看结果，问「和你想的一样吗？为什么呢？」
  3. 换溶解（盐在水里去哪了）或两色混成新色，重复「猜—试—说」。
  4. 不急着给标准答案，先收集孩子的解释。
- difficulty_ladder: 更易—只玩 2 件、只问浮 / 沉；更难—让孩子自己提出一个想验证的问题（如「热水化糖更快吗」）并设计怎么试。
- temperament_fit_notes: 高活跃—户外或浴室做、容许洒水、设「水只在盆里」一条规则；慢热—先让孩子旁观大人玩一轮再邀请加入；高负性情绪—去掉「猜错」的输赢感，把「和预想不一样」说成「哦原来还能这样，真有意思」。
- evidence: 🟡 「预测—观察—解释」的提问结构对应 Jirout & Klahr(2012) 的科学好奇操作化（对期望不确定性的探索）与 I/D-YC 的 D 型好奇（被「没搞懂」驱动去弄明白）（Tang et al. 2024）；成人提问轻推符合引导式游戏证据（Skene et al. 2022）。具体配方对某能力的提升无专门 RCT（部分为 ⚪ 一般性发展原理）。
- safety_notes: 用食用级颜料 / 食材，防误食非食用色素；地面防滑；4 岁以下全程看护防呛水；玻璃容器换成塑料 / 不锈钢。

---

**A6-03 散步「寻宝侦探」（观察—提问—记录）**
- type: exercise, companionship, game
- domain: 学习品质（ATL）
- targets: LRN-B 好奇与探索（主）、LRN-A 专注与坚持、（跨域：大动作-步行、语言-描述）
- age_bands: 3-4, 4-5, 5-6
- materials: 户外散步路线；可选小篮子 / 手机拍照
- steps:
  1. 出门前定一个「今天找什么」：3–4 岁「找 3 样圆的东西」，5–6 岁「找会动的、会发声的、会变色的各一样」。
  2. 边走边让孩子发现并描述，鼓励提问：「你注意到那棵树和上次有什么不一样？」
  3. 回家把发现讲给另一位家人 / 画下来。
- difficulty_ladder: 更易—只找一类（圆形），路程短；更难—记录「我的问题清单」回家一起查绘本 / 问长辈找答案（接 D 型好奇）。
- temperament_fit_notes: 高活跃—把它变成「走走停停」释放体能，多走少坐；慢热—不强迫与陌生人 / 陌生环境互动，先在熟悉路线玩；高负性情绪—天气 / 体力不佳时缩短，避免疲惫引发崩溃。
- evidence: ⚪ 一般性发展原理（户外观察 + 开放式提问培养好奇与注意，为权威育儿机构与 ELOF P-ATL 11「好奇」的常见建议）；「回家找答案」对应 I/D-YC 的 D 型好奇行为（Tang et al. 2024，🟡）。
- safety_notes: 全程牵手 / 视线内，远离车流与水域；防晒防蚊；不采摘不明植物 / 蘑菇、不接触流浪动物。

**A6-04 「我想知道」问题罐（亲子提问仪式）**
- type: companionship
- domain: 学习品质（ATL）
- targets: LRN-B 好奇与探索（主）、LRN-C 主动性与自我驱动、（跨域：语言-表达）
- age_bands: 4-5, 5-6
- materials: 一个空罐 / 盒、纸条、笔
- steps:
  1. 约定：孩子白天冒出的「为什么 / 怎么会」，大人帮忙记在纸条上投进罐里（孩子大可自己画符号）。
  2. 每周挑一两个晚上,抽一张一起想办法找答案（翻绘本、问人、做小实验、查图片）。
  3. 重点不是给标准答案，而是示范「不知道→一起去找」的过程。
- difficulty_ladder: 更易—大人主动多投几个问题、当晚就解答；更难—让孩子自己想「我们可以怎么查」，并把找到的答案讲出来。
- temperament_fit_notes: 慢热 / 内向—接受孩子用画代替说、用点头选择问题；高活跃—把「找答案」做成动手小任务而非久坐讨论；高负性情绪—不为「没找到答案」施压，肯定「提了个好问题」本身。
- evidence: 🟡 鼓励并珍视孩子提问、把「没搞懂」转化为探究，对应 I/D-YC 的 I 型 / D 型好奇构念与 ELOF P-ATL 11；成人示范「一起找答案」契合自主支持促进探索的研究取向（自主支持-坚持相关，🟡）。仪式本身无专门 RCT（⚪）。
- safety_notes: 低风险；注意保护孩子提问的积极性，不评判问题「幼稚 / 简单」。

### B 组 · 专注与坚持（主练 LRN-A，多牵 LRN-E/F）

---

**A6-05 「跳一跳够得着」拼图阶梯**
- type: game
- domain: 学习品质（ATL）
- targets: LRN-A 专注与坚持（主）、LRN-E 掌握愉悦与挑战取向、LRN-F 面对挫折的恢复、（跨域：精细动作、视空间）
- age_bands: 3-4, 4-5, 5-6
- materials: 几套不同块数的拼图（如 6 / 12 / 24 / 48 片），或自制（把一张图 / 旧明信片剪成块）
- steps:
  1. 选一套「比孩子上次轻松完成的略多几块」的拼图——制造中等挑战。
  2. 大人坐旁边但**不代劳**：孩子卡住时先等 10–20 秒，再用提示而非给答案（「找找有没有同样颜色的边」）。
  3. 完成后做过程表扬：「你刚才一直在试不同的块，没放弃，所以拼出来了！」
- difficulty_ladder: 更易—减少块数 / 留个角已拼好 / 给完整图当参照；更难—增加块数 / 拿掉参照图 / 计时挑战自己（与自己比，不与人比）。
- temperament_fit_notes: 高活跃—缩短单次时长、分两三次完成、允许站着拼；慢热—不催、不围观，让其按自己节奏；**高负性情绪**—从远低于其能力的块数起步累积成功体验，卡住时先共情（「这块有点难，是不是有点急」）再提示，必要时一起拼最后两块保住成就感。
- evidence: 🟢/🟡 「中等难度最能激发专注与坚持」是掌握动机定义的核心（DMQ_def；Morgan 等）；成人**不代劳、用提示而非答案**对应自主支持促进幼儿挑战任务坚持、侵入削弱坚持的观察研究（🟡）；过程表扬对应 Gunderson et al.(2013)、Kamins & Dweck(1999)（🟢 表扬类型→动机框架前体）。
- safety_notes: 小块拼图对 3 岁以下 / 爱放嘴里的孩子有误吞风险，选大块；监督收纳防遗失被踩。

**A6-06 多米诺 / 积木「不打断」专注时段**
- type: game, companionship
- domain: 学习品质（ATL）
- targets: LRN-A 专注与坚持（主）、LRN-D 创造与灵活、LRN-F 面对挫折的恢复
- age_bands: 3-4, 4-5, 5-6
- materials: 多米诺骨牌 / 积木 / 纸盒等可叠可推的物
- steps:
  1. 孩子专心搭 / 排时，大人**管住手和嘴**：不指挥、不抢着摆「更好看的」、不替他扶。
  2. 只在孩子求助或邀请时介入；他被推倒沮丧时先共情（「搭了那么久突然倒了，是会难受」），再问「想重搭还是换个搭法？」
  3. 完成后让他自己推倒 / 展示，享受掌握愉悦。
- difficulty_ladder: 更易—块数少、目标低（搭 3 层）；更难—搭有功能的结构（能立住的「桥」「门」）或多米诺连锁。
- temperament_fit_notes: 高活跃—接受「搭一会推一会」的循环，把推倒也当奖励；慢热—独处搭建对其友好，不必社交；高负性情绪—倒塌易引发崩溃，可先在地毯上搭（更稳）、预告「积木有时会倒，倒了我们再来」。
- evidence: 🟡 成人「不打断、不侵入」给孩子完整的专注与坚持机会，对应父母侵入与幼儿坚持负相关、自主支持与坚持正相关的研究；积木 / 建构游戏与执行功能（行为自我调节、任务切换）相关（多项研究含 RCT，🟡）。
- safety_notes: 大件积木防砸脚 / 砸头；不在高处搭后任其坠落；木质积木检查无毛刺。

**A6-07 「先做完再玩」小任务计划板**
- type: companionship, game
- domain: 学习品质（ATL）
- targets: LRN-A 专注与坚持（主，含 EF 工作记忆 / 抑制）、LRN-C 主动性与自我驱动
- age_bands: 4-5, 5-6
- materials: 一块小白板 / 纸，画 2–3 格步骤图（可用贴纸 / 简笔画）
- steps:
  1. 把一件日常事拆成 2–3 步并画出来（如「收积木→洗手→吃水果」）。
  2. 让孩子边做边「打勾」，做完一步划掉一步——把抽象的「坚持到完成」变可见。
  3. 5–6 岁可让孩子自己排步骤顺序、自己定「先做完哪件再玩」。
- difficulty_ladder: 更易—只 2 步、大人陪做；更难—3–4 步、加入一个「枯燥但必要」的环节（如整理），练习忍耐完成。
- temperament_fit_notes: 高活跃 / 易分心—步骤越少越好、每步即时打勾给反馈、移除周围诱惑物；慢热—预告流程减少过渡焦虑；高负性情绪—步骤卡住时拆得更小，避免「做不到全部」的挫败。
- evidence: ⚪/🟡 「两三步指令的记住并照做」「先做完再玩」对应 EF 工作记忆与抑制控制的行为锚点（Garon, Bryson & Smith 2008；CHEXI）与 ELOF 认知自我调节子域；可视化计划板源自「Tools of the Mind」等 EF 课程的「play plan / 计划」思想，但需说明 Tools 的 RCT 证据**有正有负、并非一致**（🟡，Diamond et al. 2007 阳性；加拿大 RCT 仅对初始多动 / 注意问题高者显著）。
- safety_notes: 低风险；注意别把它变成施压打卡，保持游戏感。

**A6-08 平衡木 / 走线「再练一次」体能坚持**
- type: exercise, game
- domain: 学习品质（ATL）
- targets: LRN-A 专注与坚持（大动作坚持，主）、LRN-E 掌握愉悦、LRN-F 抗挫、（跨域：大动作-平衡协调）
- age_bands: 3-4, 4-5, 5-6
- materials: 地上贴一条胶带直线 / 公园路缘（低矮安全处）/ 平衡木；可放小目标物
- steps:
  1. 孩子沿线走，从「不掉下来」到「端着小物走」「倒着走」逐步加难。
  2. 没走稳时鼓励「再来一次，看这次能走几步」，强调进步而非完美。
  3. 记录「今天走了 N 步 / 走到第几个贴纸」，和昨天的自己比。
- difficulty_ladder: 更易—宽线 / 牵一只手 / 短距离；更难—端水杯走 / 单脚短停 / 闭眼站一下（有人扶）。
- temperament_fit_notes: 高活跃—正好释放体能，可设连续关卡；慢热—先牵手走、不在众目下表演；高负性情绪—把「掉下来」常态化（「掉下来再上去就行」），避免完美主义崩溃；低活动量 / 不爱动—缩短、配喜欢的音乐增加意愿。
- evidence: 🟡 大动作任务上的反复练习对应 DMQ 的「大动作坚持」分量表（Morgan 等 DMQ 18）；「与自己比、强调进步」契合过程取向 / 成长前体（Gunderson；Kamins & Dweck，🟢 表扬类型证据）。平衡练习本身的体能价值为 ⚪ 一般性发展原理。
- safety_notes: **平衡木 / 路缘必须低矮、地面平整柔软（草地 / 垫子），全程近身保护防摔**；不在马路边、池边、高台进行；穿防滑鞋。

**A6-09 「今天你来当小老师 / 小主厨」（角色赋权）**
- type: companionship, game
- domain: 学习品质（ATL）
- targets: LRN-C 主动性与自我驱动（主）、LRN-E 掌握愉悦、（跨域：语言-表达、生活自理）
- age_bands: 4-5, 5-6
- materials: 因角色而定（简单食材 / 一本绘本 / 家务用具）
- steps:
  1. 给孩子一个真实的「负责人」角色：做凉拌菜的小主厨、给家人讲绘本的小老师、摆碗筷的小管家。
  2. 大人退为「助手」，只在被请求时帮忙，让孩子做选择和发起。
  3. 完成后请他复盘「你是怎么决定先做哪一步的？」
- difficulty_ladder: 更易—大人多示范、给「二选一」的有限选择；更难—让孩子自己规划全过程、分配大人的任务。
- temperament_fit_notes: 慢热 / 害羞—从只对家人的小角色开始，不强迫表演；高活跃—给能动手走动的角色；高负性情绪—降低「做对」的压力，强调「你来安排」本身就很棒，过程中遇阻先共情。
- evidence: 🟡 给予选择权与发起空间 = 自主支持，与幼儿主动性、坚持、内在动机正相关（自主支持研究，🟡）；对应 ELOF P-ATL 10「主动与独立」、DMQ「与成人社会性坚持」（Morgan 等）。
- safety_notes: 「小主厨」避免用火 / 利刀 / 滚烫物，安排洗、拌、摆等冷加工步骤；全程看护，食材防误食过敏原。

**A6-10 自选游戏角 + 「你想玩什么」开场**
- type: companionship
- domain: 学习品质（ATL）
- targets: LRN-C 主动性与自我驱动（主）、LRN-B 好奇与探索、LRN-D 创造与灵活
- age_bands: 3-4, 4-5, 5-6
- materials: 一个固定的「游戏角」放几类开放材料（积木、绘本、画材、假装道具），孩子可自取
- steps:
  1. 每天留一段「孩子主导」的自由 / 半自由游戏时间。
  2. 大人用「你今天想玩什么？」开场，把发起权交给孩子；他选定后大人**跟随**而非主导。
  3. 适时用开放式提问轻推深入（「然后呢？」「如果……会怎样？」）但不夺走主导权。
- difficulty_ladder: 更易—材料少而熟悉、大人陪同；更难—引入新材料组合、让孩子自己定「今天的玩法主题」并坚持玩完。
- temperament_fit_notes: 高活跃—允许频繁切换、留出大动作空间；慢热—接受较长的「热身观望」，不催选择；高负性情绪 / 选择困难—把「想玩什么」缩成「积木还是画画」二选一，减轻决策压力。
- evidence: 🟡 跟随孩子兴趣、成人轻引导（引导式游戏）优于纯灌输 / 纯放养（Skene et al. 2022）；自主支持促进主动性与内在动机（🟡）；对应 ELOF P-ATL 10。
- safety_notes: 游戏角材料按龄筛选（无小零件误吞、无尖锐），固定收纳防绊倒。

**A6-11 「我的小目标」打卡（自定目标 + 进度可见）**
- type: companionship
- domain: 学习品质（ATL）
- targets: LRN-C 主动性与自我驱动（主，目标导向萌芽）、LRN-A 专注与坚持、LRN-E 挑战取向
- age_bands: 5-6
- materials: 一张小目标卡 / 贴纸表
- steps:
  1. 帮孩子定一个**他自己想达成**的小目标（搭一座更高的塔 / 学会系一个扣 / 连续走完平衡木）。
  2. 把目标拆成几步、画进度，孩子每进一步贴一颗星。
  3. 达成后一起复盘「你是怎么做到的」，强调努力与方法（过程表扬）。
- difficulty_ladder: 更易—一天能达成的微目标；更难—跨几天的目标，练习延迟满足与持续投入。
- temperament_fit_notes: 高负性情绪 / 易放弃—目标定得很小、近，多设中间里程碑保住信心；高活跃—目标偏动手 / 体能类；慢热—由孩子私下完成，不公开比较。
- evidence: 🟡 自定目标并坚持对应 ELOF P-ATL 10 与掌握动机的目标导向（DMQ_def）；过程表扬复盘对应 Gunderson(2013) / Kamins & Dweck(1999)（🟢）。「贴纸表」作为外部奖励需适度——过度物质奖励可能削弱内在动机（自我决定理论共识，🟡），故重点放在自定目标与过程肯定，而非贴纸本身。
- safety_notes: 低风险；避免把目标变成大人的期望强加，确保是孩子自选。

### D 组 · 创造与灵活（主练 LRN-D，多牵 LRN-B）

**A6-12 「一物多玩」头脑风暴（发散思维）**
- type: game, companionship
- domain: 学习品质（ATL）
- targets: LRN-D 创造与灵活（主，发散思维 / 流畅性）、LRN-B 好奇与探索、（跨域：语言）
- age_bands: 3-4, 4-5, 5-6
- materials: 一件普通物（纸杯 / 旧报纸 / 一根绳 / 几块积木）
- steps:
  1. 拿一件普通物问：「这个除了原来的用法，还能当成什么 / 怎么玩？」
  2. 接住孩子每个点子（哪怕天马行空），用「还有呢？」鼓励多说几个。
  3. 挑一两个真的试着玩起来。
- difficulty_ladder: 更易—大人先抛 1–2 个示范点子；更难—限定主题（「只想能在客厅玩的」）或比「谁想得多」（与自己上次比）。
- temperament_fit_notes: 高活跃—边说边动手试，别只坐着想；慢热—允许长时间不答、用动作代替说；高负性情绪—强调「没有错答案」，不评判点子好坏。
- evidence: 🟡 发散思维 / 想象游戏与创造力相关（假装游戏—创造力文献，Russ 等；但因果有争议，Lillard et al. 2013）；对应 ELOF P-ATL 12「创造」与 EF 认知灵活。措辞为「提供发散练习机会」而非「提升创造力」。
- safety_notes: 试玩点子前先做安全过滤（不爬高、不往身上套绳 / 袋）；旧报纸防墨蹭嘴。

**A6-13 假装 / 角色扮演剧场（社会戏剧游戏）**
- type: game, companionship
- domain: 学习品质（ATL）
- targets: LRN-D 创造与灵活（主）、LRN-C 主动性、（跨域：语言-叙事、社会情绪-换位）
- age_bands: 3-4, 4-5, 5-6
- materials: 家里现成「道具」（旧衣帽、纸箱、毛绒玩具、厨房玩具），无需购买
- steps:
  1. 起一个情境（开商店 / 看医生 / 开餐厅 / 探险），孩子和大人各扮角色。
  2. 用「积木当电话、纸箱当汽车」鼓励以物代物；跟随孩子的剧情走向。
  3. 中途抛入小变化（「顾客没带钱怎么办？」）让剧情转弯，练灵活。
- difficulty_ladder: 更易—简单熟悉情境（吃饭 / 睡觉），大人多带；更难—多角色 / 有冲突情节 / 孩子自编结局。
- temperament_fit_notes: 慢热—从一对一与家人扮起，不强推同伴戏；高活跃—选有动作的情境（消防员 / 探险）；高负性情绪—避免太多突发冲突剧情，变化温和引入。
- evidence: 🟡 社会戏剧 / 假装游戏与发散思维、认知灵活、问题解决相关（Russ 等综述）；以物代物对应 ELOF P-ATL 12 与本工具 LRN-D 行为锚点。因果证据有争议（Lillard et al. 2013），故标相关 / 练习机会。
- safety_notes: 道具无尖锐 / 长绳（防缠绕）/ 小零件；纸箱「车」别从高处推；扮演不涉及危险模仿。

**A6-14 「换个法子」灵活挑战（变规则 / 找新路）**
- type: game
- domain: 学习品质（ATL）
- targets: LRN-D 创造与灵活（主，认知转换）、LRN-F 抗挫（换策略再试）
- age_bands: 4-5, 5-6
- materials: 任意可变规则的活动（简单棋 / 分类游戏 / 走迷宫纸）
- steps:
  1. 先按原规则玩熟一轮。
  2. 玩到一半改一条小规则（「这次反过来，最小的赢」「这次走另一种颜色的格」），看孩子能否切换。
  3. 一种走法行不通时，引导「这条路堵了，还能怎么走？」鼓励换策略而非卡死。
- difficulty_ladder: 更易—只改一条很明显的规则、大人提示切换；更难—连续变规则 / 让孩子自己出一条新规则。
- temperament_fit_notes: **低灵活 / 偏刻板或高负性情绪**—变规则前**预告**（「等下我们要换个玩法哦」），给适应时间，一次只变一点；高活跃—快节奏变化反而更吸引；慢热—不在压力下临时变。
- evidence: 🟡 规则切换 / 换策略对应 EF 认知灵活性 / 任务切换（Garon, Bryson & Smith 2008）；引导式游戏在「任务切换」上优于直接灌输（Skene et al. 2022，g≈0.40，🟢 对该结局变量）。
- safety_notes: 低风险；注意频繁变规则对刻板 / 易挫孩子可能引发烦躁，按其反应调节频率。

**A6-15 开放式美工 / 涂鸦（过程重于成品）**
- type: game, companionship
- domain: 学习品质（ATL）
- targets: LRN-D 创造与灵活（主）、LRN-B 好奇、LRN-E 掌握愉悦、（跨域：精细动作）
- age_bands: 3-4, 4-5, 5-6
- materials: 纸、蜡笔 / 颜料、胶水、废旧材料（纸盒、瓶盖、布头）
- steps:
  1. 提供材料但**不给范例 / 不要求画得像**，让孩子自由创作。
  2. 描述而非评判：「你用了好多红色」「这里贴了三个瓶盖」，而不是「画得真好 / 这是什么呀画得不像」。
  3. 完成后问「能跟我讲讲它吗？」让孩子赋予意义。
- difficulty_ladder: 更易—只用一两种材料、自由涂；更难—给一个开放主题（「做一个会飞的东西」）或拼贴组合多种材料。
- temperament_fit_notes: 高负性情绪 / 完美主义—强调「怎么弄都行、没有错」，避免示范「正确画法」引发挫败；高活跃—大幅面纸 / 户外、可站可动；慢热—独立创作友好，不必展示。
- evidence: ⚪/🟡 开放式（无范例）美工保护内在动机与发散表达，对应 ELOF P-ATL 12；「描述性反馈而非评判 / 聪明表扬」契合过程取向（Gunderson；Kamins & Dweck，🟢）。具体美工→创造力提升无强 RCT（⚪ 一般性原理）。
- safety_notes: 用无毒 / 可水洗颜料胶水；3 岁以下防误食颜料 / 小装饰物；剪刀用安全圆头并看护。

### E 组 · 掌握愉悦与挑战取向 + 抗挫（主练 LRN-E / LRN-F，过程表扬主线）

**A6-16 「再难一点点」挑战阶梯游戏**
- type: game, exercise
- domain: 学习品质（ATL）
- targets: LRN-E 掌握愉悦与挑战取向（主）、LRN-A 专注与坚持、LRN-F 抗挫
- age_bands: 3-4, 4-5, 5-6
- materials: 任意可分级的活动（叠杯 / 投掷进筐 / 套圈 / 拍球）
- steps:
  1. 从孩子能轻松成功的难度起步，积累几次成功。
  2. 每成功几次，**只加一点点**难度（筐远 10 cm、多叠一层），保持「跳一跳够得着」。
  3. 成功时过程表扬（「你调整了角度才投进的」），失败时常态化（「差一点，再来」）。
- difficulty_ladder: 更易—大幅降难、保证高成功率（适合 LRN-E/F 偏低、易放弃的孩子）；更难—连续挑战、自己设定下一关。
- temperament_fit_notes: **高负性情绪 / 回避挑战**—难度加得极缓，先「赢」够了再升级，卡住先共情；高活跃—选体能投掷类、节奏快；慢热—私下玩、不比赛。
- evidence: 🟢/🟡 「中等难度最优」是掌握动机的定义核心（DMQ_def；Morgan 等）；逐级递增维持挑战与心流思想（Csikszentmihalyi，框架性）；过程表扬→掌握取向（Kamins & Dweck 1999；Gunderson 2013，🟢）。
- safety_notes: 投掷物选软质（布球 / 海绵），不向人投；活动区清空易碎物；体能类防滑防撞。

**A6-17 过程表扬「家庭口头禅」（成人语言习惯改造）**
- type: companionship
- domain: 学习品质（ATL）
- targets: LRN-F 面对挫折的恢复（主，成长前体）、LRN-E 挑战取向
- age_bands: 3-4, 4-5, 5-6
- materials: 无（改造的是大人的反馈语言）
- steps:
  1. 把「你真聪明 / 真棒 / 真厉害」换成**过程语**：「你试了好几种方法」「你刚才很专心」「你没放弃」。
  2. 孩子受挫时,用「成长语」：「这个你还没学会，再练练就会了」「错了没关系，错误帮我们知道下次怎么改」。
  3. 大人也示范自己面对困难（「这个我也不太会，我再想想办法」）。
- difficulty_ladder: 更易—先固定记住 2–3 句过程表扬挂嘴边；更难—在真实受挫时即时、具体地用上（指出具体努力 / 策略）。
- temperament_fit_notes: 高负性情绪—受挫当下先共情情绪（「我知道你很气」）**再**说成长语，否则孩子听不进；慢热—过程表扬宜私下、平静地说；高活跃—简短即时反馈比长篇说教有效。
- evidence: 🟢 过程表扬（努力 / 策略）vs 个人 / 能力表扬，与增量 / 成长动机框架、掌握取向、抗挫正相关（Gunderson et al. 2013 纵向；Kamins & Dweck 1999 实验；Xu et al. 2023「表扬配比」）。**注意：Gunderson 原文未测学业成就，不宣称提分**。
- safety_notes: 低风险；避免完全不表扬或过度纠错，过程表扬与温暖共情并用。

**A6-18 「错误是朋友」复盘小仪式**
- type: companionship
- domain: 学习品质（ATL）
- targets: LRN-F 面对挫折的恢复（主）、LRN-D 换策略
- age_bands: 5-6
- materials: 无 / 可选一本关于「犯错也没关系」的绘本
- steps:
  1. 做错 / 没成功后，等情绪平复，平静地一起看「哪里卡住了」。
  2. 把失败重新框定为信息：「这次没成，是因为……那下次我们怎么改？」
  3. 鼓励说出 / 试一个新办法，强调「再试」本身值得肯定。
- difficulty_ladder: 更易—大人主导复盘、给出改法；更难—让孩子自己说出「下次我可以怎么做」。
- temperament_fit_notes: **高负性情绪**—务必等彻底平复后再复盘，否则变二次打击；慢热—不公开复盘；对一次失败就全盘否定自我（「我不行」）的孩子，重点拆解「是这一步没成，不是你不行」。
- evidence: 🟡 把失败归因为「还没学会 / 方法问题」而非「我不行」是成长型思维前体（Dweck 体系；Kamins & Dweck 1999 的掌握 vs 无助取向，🟢 对 5–6 岁）；对应本工具 LRN-F 行为锚点（LRN-F02/F04/F05）。
- safety_notes: 低风险；切忌在情绪高峰期说教，避免羞辱性语言。

**A6-19 「等一等再帮」忍住手陪伴法（家长策略）**
- type: companionship
- domain: 学习品质（ATL）
- targets: LRN-A 专注与坚持（主）、LRN-E 挑战取向、LRN-F 抗挫、LRN-C 主动性
- age_bands: 3-4, 4-5, 5-6
- materials: 无（任何孩子正在尝试的任务）
- steps:
  1. 孩子做有点难的事（穿鞋、开盒、拼装）时，大人默数 10–20 秒**先不出手**。
  2. 真需要帮时,给「最小帮助」：先语言提示 → 再示范一步 → 最后才动手，且做完一步就退回。
  3. 全程传递「你能行，我在这」，而非替他做完。
- difficulty_ladder: 更易—帮助阶梯靠前（多示范）；更难—延长等待、只给语言提示，让孩子自己摸索更久。
- temperament_fit_notes: **高负性情绪 / 易崩溃**—等待时间缩短、共情先行，避免等到大哭；高活跃 / 没耐心—把任务拆更小让每步快速见效；慢热—给足不被催的时间，反而表现更好；对包办型家庭（祖辈）特别提示此法。
- evidence: 🟡 父母**自主支持 / 不侵入**与幼儿在挑战任务上的坚持正相关，**侵入 / 代劳**与坚持负相关（自主支持—坚持的观察研究）；「最小帮助 / 渐撤支持」对应维果茨基「脚手架」与引导式游戏原则（Skene et al. 2022）。
- safety_notes: 仅适用于**安全**任务；涉及危险（够高处、用刀剪、靠近火 / 水）时不可「等一等」，须立即介入。

**A6-20 对话式共读（不只是念，而是问与聊）**
- type: companionship, game
- domain: 学习品质（ATL）
- targets: LRN-B 好奇与探索（主）、LRN-A 专注、LRN-D 创造、（跨域：语言-词汇 / 叙事）
- age_bands: 3-4, 4-5, 5-6
- materials: 适龄绘本（图书馆借 / 家中现有即可）
- steps:
  1. 读绘本时不照本宣科，多用开放式提问：「你看这里发生了什么？」「你猜他接下来会做什么？」「如果是你会怎么办？」
  2. 接住孩子的回答、扩展（他说「狗狗」，你接「对，一只毛茸茸的大狗，跑得好快」）。
  3. 读完聊「最喜欢哪一页 / 为什么」，鼓励复述或自编后续。
- difficulty_ladder: 更易—指物命名、问「这是什么」（3–4 岁）；更难—问因果 / 推测 / 假设（「为什么 / 如果」）、让孩子复述整个故事（5–6 岁）。
- temperament_fit_notes: 慢热 / 话少—接受用点头 / 指认回答，不逼着说；高活跃 / 坐不住—选互动翻翻书、缩短单次时长、可边读边演；高负性情绪—避免追问到孩子烦躁，跟随其兴趣页停留。
- evidence: 🟢 对话式阅读（Whitehurst 等 1988）是被反复验证的早期读写干预，对儿童语言有中—大效应，并对注意、社会情绪有更广益处（WWC 报告；多项 RCT 与元分析）；开放式提问拉伸好奇与思维（与好奇 / ELOF P-ATL 11 一致）。
- safety_notes: 低风险；屏幕电子书需控时（参照月龄屏幕指南），优先纸质亲子共读。

**A6-21 多日「小小项目」（持续投入一个主题）**
- type: companionship, game
- domain: 学习品质（ATL）
- targets: LRN-A 专注与坚持（跨日，主）、LRN-B 好奇、LRN-C 主动、LRN-E 挑战
- age_bands: 5-6
- materials: 随主题定（种一颗豆 / 养蚕 / 做一本「我的恐龙书」/ 搭一座大城堡）
- steps:
  1. 和孩子选一个他感兴趣、需要几天的「项目」。
  2. 每天投入一小段（浇水观察 / 画一页 / 搭一部分），记录进展。
  3. 跨日坚持本身就是目标；完成后回顾「我们坚持了 N 天做出来了」。
- difficulty_ladder: 更易—2–3 天的短项目、大人多参与；更难—一两周、孩子主导记录与决策。
- temperament_fit_notes: 高活跃 / 难持续—选每天有明显变化的（种子发芽）维持兴趣；慢热—选其深爱的主题（恐龙 / 车）更易坚持；高负性情绪—中途遇挫（种子没发芽）时引导「再试一次 / 换个方法」，借机练 LRN-F。
- evidence: 🟡 跨时段持续投入对应 DMQ 的长程坚持与 ELOF 主动 / 坚持子域；基于兴趣的项目契合 Hidi & Renninger 兴趣发展四阶段（从情境兴趣→持久个人兴趣，HR2006）与引导式游戏。
- safety_notes: 种养类防误食种子 / 接触动物卫生（养蚕 / 小动物后洗手）；工具按龄安全。

---

**A6-22 唱跳「冻住」反应游戏（音乐口令 / 红灯绿灯）**
- type: exercise, game
- domain: 学习品质（ATL）
- targets: LRN-A 专注与坚持（抑制控制，主）、LRN-D 灵活、（跨域：大动作、努力控制 EFFCTRL）
- age_bands: 3-4, 4-5, 5-6
- materials: 一段音乐 / 你的口令；空地
- steps:
  1. 音乐响就跳舞 / 走，音乐停（或喊「冻住」）就立刻不动。
  2. 5–6 岁加规则反转（「这次音乐停才动、响了不许动」）练抑制 + 灵活。
  3. 也可玩「红灯停绿灯行」，加入「黄灯慢慢走」。
- difficulty_ladder: 更易—只玩「停 / 走」、节奏慢；更难—规则反转 / 多口令 / 加「只有听到拍手才停」的选择性反应。
- temperament_fit_notes: 高活跃—极佳的「能动又练自控」出口，先让其尽情动再练停；慢热—先看大人玩、人少时玩；高负性情绪—输赢淡化，不淘汰出局，重在参与。
- evidence: 🟡 「动 / 停」与规则反转练习反应抑制与认知灵活（EF 核心，Garon, Bryson & Smith 2008）；此类游戏是「Tools of the Mind」等 EF 课程常用成分，**但 Tools 的 RCT 证据不一致**（Diamond et al. 2007 阳性；其他 RCT 未复现，🟡），故标为「练习机会」。
- safety_notes: 场地清空障碍防摔撞；「冻住」别要求长时间憋住单脚站（防摔）；室内防滑。

**A6-23 自然 / 户外自由探索时间（非结构化游戏）**
- type: exercise, companionship
- domain: 学习品质（ATL）
- targets: LRN-B 好奇（主）、LRN-C 主动、LRN-D 创造、（跨域：大动作）
- age_bands: 3-4, 4-5, 5-6
- materials: 公园 / 小区 / 院子等户外环境
- steps:
  1. 留出一段「没有安排」的户外时间，让孩子自己决定玩什么（挖土、踩水、看蚂蚁、捡树枝搭东西）。
  2. 大人在安全范围内**少干预**，跟随并偶尔用开放式提问点燃好奇。
  3. 接纳「弄脏」是探索的一部分。
- difficulty_ladder: 更易—熟悉的小范围、大人近距离陪；更难—更大空间 / 更多自主决定（接 LRN-C）。
- temperament_fit_notes: 高活跃—首选释放出口，给足奔跑空间；慢热—在熟悉、人少的户外更敢探索，不催；高负性情绪—避开过热 / 过累 / 过饿时段；对「怕脏」敏感的孩子循序渐进。
- evidence: ⚪/🟡 户外非结构化游戏支持好奇、主动与体能，是权威育儿机构与体力活动指南的普遍建议（WHO 5 岁以下身体活动指南，🟡 对体能 / 久坐部分）；自主探索契合 ELOF P-ATL 10/11（⚪ 对「创造力」等具体声称）。
- safety_notes: 持续看护，远离车流 / 水域 / 高处；防晒防蚊防晒伤；不接触流浪动物、不食野果野菌；玩耍后洗手。

**A6-24 「我会自己来」生活自理挑战（穿衣 / 整理 / 倒水）**
- type: companionship, exercise
- domain: 学习品质（ATL）
- targets: LRN-A 专注与坚持（主）、LRN-C 主动、LRN-E 掌握愉悦、LRN-F 抗挫、（跨域：精细动作、生活自理）
- age_bands: 3-4, 4-5, 5-6
- materials: 日常生活情境（衣物、扣子 / 拉链、小水壶、收纳箱）
- steps:
  1. 把一件自理任务交给孩子自己做（穿外套、扣扣子、把玩具归类收好、倒半杯水）。
  2. 大人忍住代劳，预留时间，允许慢、允许做不完美。
  3. 做成时享受「我自己做到了」的掌握愉悦，过程表扬其努力。
- difficulty_ladder: 更易—大人完成大部分、留最后一步给孩子「收尾成功」；更难—独立完成全过程、自己想办法解决卡点（扣子对不齐怎么办）。
- temperament_fit_notes: 高负性情绪 / 易急—从「留最后一步」起步保住成功感，卡住先共情；高活跃—把整理变成「限时小游戏」；慢热—多给不被催的时间；对祖辈包办家庭特别提示「放手让孩子自己来」。
- evidence: 🟡 在真实任务上自己尝试、成人不代劳，对应自主支持促进坚持与主动（🟡）、DMQ 掌握愉悦与坚持（Morgan 等）、ELOF P-ATL 10；过程表扬对应 Gunderson(2013)（🟢）。自理本身是《3–6 岁儿童学习与发展指南》健康领域的目标（MOE2012）。
- safety_notes: 倒水用小壶防烫（不给热水）；整理时防夹手 / 砸落；穿衣避免长绳帽绳（防勒）。

## 4. 给分析 skill 的使用建议（裁剪逻辑）

1. **按个体内画像选条**：孩子哪个 LRN 子维度**相对待发展**，优先推该维度为主 `targets` 的活动；哪个是**相对优势**，给「顺势加难」的活动（用 difficulty_ladder 的「更难」侧）。
2. **按气质裁剪**：读取温度计（TMP）画像（高活跃 / 慢热 / 高负性情绪等），套用对应 `temperament_fit_notes`，**优先匹配而非纠正气质**（goodness-of-fit）。
3. **按年龄启用**：仅推 `age_bands` 含该孩子段位的活动。
4. **过程表扬是贯穿主线**：无论推哪条，都建议附上 A6-17（过程表扬口头禅）与 A6-19（忍住手）作为「家长怎么陪」的通用底层策略。
5. **措辞铁律**：低分维度一律说「还在发展中 / 可以多创造机会」，**不下「落后 / 缺陷」判定**，与测评报告口径一致。
