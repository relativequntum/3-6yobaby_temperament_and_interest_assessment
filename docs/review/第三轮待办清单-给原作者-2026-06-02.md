## A. 发布前合规闸门（🟧 high — 进入公开发布前必须完成）

### ☐ T-1　产出产品级《量表许可与对齐边界表》
- **做什么**：在**产品仓库**（不只是调研简报 08）内建一张表，逐母量表说明合规边界。
- **改哪里**：新增 `docs/许可与对齐边界表.md`（或并入 08）。
- **建议表头**：`母量表 | 许可/版权状态 | 我们采用了什么（构念名/高阶因子/锚点风格） | 明确未采用什么（原题文字、整套子维度的选择与排列顺序） | 对应 source key`。
- **至少覆盖**：CBQ、SDQ、DECA-P2、ASQ-3、ASQ:SE-2、儿心-II（WS/T 580-2017）、DMQ、Baumrind/Maccoby&Martin/Chao、PSDQ、HOME、MOE2012《3-6岁指南》。
- **验收标准**：表内每个 `item-bank.source` 出现过的母量表都有一行；每行四列填满；"未采用什么"明确写到"原始题目文字 + 整套子维度选择与排列顺序"。
- **出处**：R2 §3.2 H-5 / §5 N-1（上轮 F6）。

### ☐ T-2　补 source key → 文献映射表
- **做什么**：`item-bank` 里的缩写出处键（如 `DECA-SR`/`DECA-AT`/`SDQ-Pro`/`MORGAN-DMQ`/`PSDQ2001`/`HOME1979` 等）逐一映射到完整文献。
- **改哪里**：`docs/source-legend.md`，或在 item-bank 顶层加 `source_legend` 字段。
- **验收标准**：题库中实际出现的每个 source key 都能在映射表查到完整文献；无孤儿 key。
- **出处**：R2 §3.2 H-5。

### ☐ T-3　CBQ / DECA-P2「整套编排」侵权风险判定
- **做什么**：判定本工具 SEL/TMP 子维度是否在"**选择 + 排列顺序**"上与 DECA-P2 三保护因子 / CBQ 维度集高度同构（版权不保护构念名，但保护"选择与编排"）。若同构，调整子维度集合或排序以拉开距离。
- **改哪里**：结论写入 T-1 的边界表；如需调整则改 `item-bank` + 蓝图 §2。
- **验收标准**：边界表中对"编排是否同构"给出明确判定与依据；若判为同构，已有去同构动作记录。
- **出处**：R2 §5 N-1。

## B. 建议补（🟡 medium — 质量与契约稳健性）

### ☐ T-5　成对正反题渲染层打散（REV-03 落地）
- **做什么**：规则与 `consistency_pair_id`（cp-1~4）已就位、蓝图 §4-B REV-03 也写了"间隔≥2题"，但 `index.html` 仍按题库物理顺序出题、成对题相邻。需在渲染层真正打散。
- **改哪里**：`questionnaire/index.html` 的 `renderSection()`：对带同一 `consistency_pair_id` 的题做最小错位（同 section 内用其他题隔开 ≥2 题）。
- **验收标准**：实跑问卷，`SEL-08/09`、`INT-10/11`、`INT-12/13`、`LRN-01/02` 四对中，每对两题在屏幕上不相邻（间隔≥2题）。
- **出处**：R2 §3.3 / §5 N-2。

### ☐ T-6　sample-export 一致性纳入提交前/CI 校验
- **做什么**：把"样例必须与契约和题库一致"做成可自动执行的校验，防止未来题库改动再次产生样例漂移（上轮 XS-01/02 即此类漂移）。
- **改哪里**：新增 `tests/`（或 git pre-commit / CI），脚本断言：
  (a) `sample-export.json` 通过 `schema/export.schema.json`（ajv 2020）；
  (b) 每条 `anchor_shown` ∈ 对应题 `anchors_by_band[age_band]` ∪ `{null}`；
  (c) 每条 `question_text` == item-bank 对应题 `text`（逐字）；
  (d) `cluster`/`report_subscale`/`consistency_pair_id` 与题库一致。
- **验收标准**：故意改坏一条样例锚点 → 校验报错；正常样例 → 全过。
- **出处**：R2 §3.1 L-3 残留 / §5 N-5。（注：复核侧已用 Playwright+ajv 验证过当前样例通过，本项是把它固化为长期门禁。）
