# 隐私说明（给家长）

> 这份说明用大白话告诉您：这份「3–6岁幼儿发展优势与兴趣画像测评」会收集哪些信息、用来做什么、存在哪里、您有哪些权利。请在开始填写前花两分钟读一读。
> 版本：1.0　适用页面：`questionnaire/index.html`（自适应问卷）　最近更新：2026-06-02

---

## 一句话概括

**本测评是一个纯本机网页，您填写的所有内容只留在您自己的手机/电脑浏览器里，不会上传到任何服务器，也不会发给我们或任何第三方。** 要不要把结果分享给别人，完全由您自己决定。

---

## 1. 我们收集哪些信息、用来做什么

为了生成贴合孩子的画像报告，问卷会请您填写以下内容。我们坚持「最小必要」——只问对生成报告真正有用的：

| 收集的信息 | 用途 | 是否必填 |
|---|---|---|
| 孩子的**出生年月**（精确到月） | 自动判断年龄段（3–4 / 4–5 / 5–6），切换对应的发展锚点；计算月龄 | 必填 |
| 孩子的**性别** | 仅让报告措辞更自然（如「他/她」），**不**用于和别人比较，**不**改变任何评分 | 必填 |
| 孩子的**昵称** | 报告里用来称呼孩子；**可留空**，留空时统一称「孩子」 | 选填 |
| **填写人与孩子的关系**（妈妈/爸爸/祖辈/其他主要照看人） | 在报告中说明「这是谁观察到的孩子」，并帮助判断结果的熟悉度 | 必填 |
| **每日相处时长** | 同上：相处越多，观察越充分；用于提示结果的参考强度 | 必填 |
| 各题的**作答**（行为/兴趣频率、家庭环境、开放题文字） | 生成发展优势与兴趣画像、个性化陪伴建议 | 视题目而定 |
| **作答过程信息**（开始/提交时间、各部分用时、是否从草稿续填） | 仅作「填写是否从容」的弱参考，帮助说明结果置信度 | 自动记录 |

**我们不会收集**：孩子的真实姓名、身份证件号、人脸照片、住址、联系方式、定位、设备识别码等。报告里出现的随机标识 `child_id` 只是**为这一份作答临时生成的随机串**，仅用来标记本次作答，**不会跨次自动关联到同一个孩子**，也无法用它反推出孩子身份。

---

## 2. 数据存在哪里：纯本机、不上传

- 本问卷是一个**纯静态网页，没有后端服务器**。我们已确认页面中没有任何向外发送数据的代码（无网络请求、无第三方统计、无外部字体/脚本/CDN）。
- 您填写的内容**全程只在您本机浏览器内处理**。生成的报告/导出文件（JSON、PDF、Excel、Markdown）是在您本机生成、由您**自己另存或转发**——要不要发、发给谁，由您决定。
- 即使孩子的出生月龄不在适用区间（提示「越界 out_of_range」）您仍选择继续填写，数据**同样只存在本机、不上传**。

## 3. 关于「草稿」：明文留存与一键清除

为了支持中途暂停、之后接着填，问卷会把**未完成或已完成的草稿**保存在浏览器的本地存储（`localStorage`）里：

- 草稿内容包含：**昵称、出生年月、`child_id`、以及全部已作答内容**。
- 草稿是**明文保存**的（未加密），但**只存在您这台设备的浏览器里、不会上传**。
- **提交后草稿默认仍然保留**，方便您再次导出或查看，直到您主动清除。
- 完成页提供「**清除本机草稿**」按钮，**一键即可彻底删除**本机草稿。
- 提示：如果是**公用或借用的设备**，建议您**导出结果文件后立即点「清除本机草稿」**；清空浏览器数据/缓存也会一并清除草稿。

## 4. 您的权利：保留与删除

因为数据只在您本机、由您掌握，所以您拥有完全的控制权：

- **保留权**：您可以一直保留草稿与导出文件，自行决定保存多久、存在哪里。
- **删除权**：随时可在完成页点「清除本机草稿」删除本机草稿；导出的文件由您自行删除即可。一旦清除，本机将不再保留相关作答。
- **分享的自主权**：报告/导出文件是否发给老师、家人或他人，完全由您决定；我们不经手、也收不到这些文件。
- 由于我们**从不接收、也不存储**您的数据，因此不存在「向我们申请导出/更正/删除」的环节——这些操作都在您本机由您直接完成。

## 5. 重要边界：这不是诊断

- 本测评是**发展指导性质的画像**，做的是**同一个孩子在自己身上的相对比较**（哪些方面相对突出、哪些还在发展中）。
- 它**不是**医学诊断、不是发育筛查、不是智力或天赋鉴定；**不**给孩子贴「合格/不合格」「正常/异常」标签，**不**与其他孩子比较，**不**给人群百分位或排名。
- 题目由我们参照国际与本土成熟研究框架自行编写，**不属于任何标准化诊断量表**。
- 结果会因「谁来填、哪段时间填」而略有不同，这很正常。**如果您对孩子某方面的发展有持续担心，请咨询儿童保健医生或专业老师，本测评不能替代专业评估。**

---

## 6. 合规要点（PIPL 与儿童个人信息保护）

我们按照中国《个人信息保护法》（PIPL）及《儿童个人信息网络保护规定》等要求，对**不满十四周岁未成年人**的个人信息按敏感个人信息从严对待：

- **监护人同意**：本测评由**家长/监护人**填写并就处理孩子相关信息作出**知情同意**（开始前的同意书）。请确认您是孩子的监护人或已获其授权。
- **告知充分**：上文已说明收集的字段、用途、存储位置（本机）、保留与删除方式，便于您在同意前充分了解。
- **最小必要 + 目的限定**：只收集生成报告必需的最少信息；信息仅用于本次画像与建议，不作其他用途。
- **本地处理、不出境**：数据不离开您的设备，不上传服务器，自然不涉及对外提供或跨境传输。
- **去标识化**：以**昵称 + 单次随机 `child_id`** 代替真实身份；不采集姓名、证件号、人脸、定位等直接标识。
- **可删除、可控制**：提供一键清除草稿，保障监护人的删除权与控制权。
- **安全提示**：草稿在本机为明文存储，请您像保管其他个人文件一样，注意所用设备的安全（尤其是公用设备用后及时清除）。

## 7. 联系与说明

本工具不设服务器、不收集联系方式，因此**无法、也不需要**主动联系您。若您是在某机构/老师的引导下使用，关于结果解读的问题请向该机构咨询；关于孩子发展的专业担忧，请咨询儿童保健科或专业人士。
